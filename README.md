## 교재 운영 구조

- `part01/`: 01~10장 기본 SoC 구축 교재. 현재 목차는 원래의 장별 본문 경로에 연결됩니다.
- `part02/`, `part03/`: 향후 독립된 목차·장별 본문·그림·실습 파일을 추가할 공간입니다.
- `assets/`: 통합 사이트의 공통 스타일.
- `MicroBlaze_V_SoC01_41/`: 기존 41장 교재 원본 보존 경로. 신규 과정으로 이관을 마치기 전까지 삭제하지 않습니다.

## 전환 원칙

1. 기존 원본과 상대 경로·다운로드 파일·그림을 보호합니다.
2. 각 부에 `chapters/`, `images/`, `files/` 자료를 단계적으로 이관합니다.
3. 장별 성공 화면과 실제 실습 설정을 대조한 뒤 외부 배포 본문에 반영합니다.
4. 새 경로의 모든 기능과 링크를 확인한 후 기존 41장 경로의 삭제 여부를 결정합니다.
