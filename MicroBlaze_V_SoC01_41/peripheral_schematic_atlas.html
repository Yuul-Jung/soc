04 · 2차 선정 및 RTL → AXI 확장 기준

1. 실제 재고 우선

실물 모듈명·PCB 앞뒷면·전원 및 핀맵을 확인. 저가 Ali 모듈은 동일 이름이라도 회로/전압이 달라질 수 있어 제조사별 구분.

2. 전기적 안전

Basys3의 일반 GPIO 3.3V, JXADC 아날로그 기본 0~1V, 모터 외부전원, 5V Echo 입력·I2C 5V 풀업 차단을 검토.

3. RTL 재사용성

기존 uart_core, fnd_display_4digit, led_pwm_controller, 거리측정·디바운스 회로를 우선 활용.

4. 단독 검증

센서 단독 RTL + 테스트벤치 → 합성·타이밍 → Basys3 핀 연결 → 실제 입력/출력 확인 순서. 성공 기록 전 ‘검증 완료’ 표기 금지.

5. AXI 제어화

검증된 RTL Controller에 Control/Status/Data Register와 AXI4-Lite Slave를 덧붙이고 MicroBlaze V에서 레지스터로 제어.

6. 앙상블 과제

단일 입출력 기능이 확보되면 센서 + 구동 + 표시 + 통신을 누적 조합. 기본 SoC 완성 뒤 NPU는 선택적 확장.
I2C는 통신 프로토콜 구현 부담이 상대적으로 커서 처음부터 다른 여러 기능과 동시 통합하지 않고 독립 실습 단위로 검토합니다. ESP32/Pico는 FPGA 내부 IP가 아니라 외부 MCU/무선 코프로세서 역할도 고려합니다.

05 · 입출력 앙상블 과제 후보 (순서 미확정)

스마트 조명

조도 입력 → PWM 밝기 → FND 상태 → UART 설정
CDS+XADC 또는 Pmod ALS 비교

거리 기반 안전 구동

초음파 → 모터 PWM → LED 경고 → UART 상태
5V Echo 보호·모터 별도 전원 필수

스톱워치·환경 계측

버튼/엔코더 → 타이머 → FND/OLED → PC 로그
기존 표시 RTL 재사용

무선 모니터링

센서 → AXI 상태 레지스터 → UART → ESP32/Pico
외부 MCU 펌웨어 경계 구분

로봇·모터 피드백

엔코더 → 속도 측정 → PWM → 폐루프 제어
TB6612/DRV8833/DHB1 회로 비교

영상/신호 응용

조이스틱/센서 → VGA/OLED 그래픽 → UART 명령
기존 FPGA 영상/표시 구조 활용
