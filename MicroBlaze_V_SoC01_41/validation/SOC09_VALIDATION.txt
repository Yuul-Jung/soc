SoC 09 · AXI Interrupt Controller

## 실제 확인
- AXI Timer interrupt → AXI INTC intr[0:0] → AXI INTC interrupt → microblaze_riscv_0 INTERRUPT 연결.
- AXI INTC Base Address 0x41200000, 기존 16 KiB Local BRAM 유지.
- Vivado Block Design/XSA와 Vitis Platform soc09_axi_interrupt_platform, Application soc09_axi_interrupt 성공.
- AXI Timer Handler를 인터럽트에 등록하여 CPU에서 실행하는 구조 검증.
- Debug WATCH interrupt_count 값이 12 → 35로 증가; led_state 0 → 1 변화 확인.
- Basys3 LED0 반복 점멸 실기 확인.

## 판정 경계
- interrupt_count는 Timer 인터럽트 처리 횟수. 일시 정지 시 timer_event=0인 화면은 이벤트가 Main에서 처리된 뒤의 상태일 수 있음.
- PG099의 IPR/SIE/CIE/IVR은 선택 레지스터이므로 실제 IP 설정에 따라 구현 여부가 달라짐.
- 인터럽트 주기의 정밀 계측값은 기록되지 않음.
