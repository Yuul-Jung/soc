SoC 07 · AXI UART Lite

## 실제 확인
- AXI UART Lite Base Address 0x40600000, RX(B18) / TX(A18) 외부 연결.
- 115200 bps / 8N1 / Polling 설정의 UART Echo Application과 10장 이전 16 KiB BRAM 구성.
- Vivado Bitstream/XSA, Vitis Platform 및 soc07_axi_uartlite ELF Build 성공.
- Basys3와 Ubuntu moserial을 연결해 송신 문자 abc가 동일하게 수신되는 Echo 동작 확인.

## 판정 경계
- 실제 보드 UART Echo 성공. AMD IP 내부 구현 XSim 기능 시뮬레이션까지 완료한 것으로 기재하지 않음.
- 벤치의 stub 인터페이스 컴파일 결과는 실제 AXI UART Lite 동작 시뮬레이션과 구별.

## 판정
해당 장의 실습 검증 완료. 확인하지 않은 별도 검사는 판정 경계에 표시.
