SoC 04 · Local BRAM Memory Map

## 실제 확인
- ILMB와 DLMB Base 0x00000000, Range 16 KiB, High 0x00003FFF.
- M_AXI_DP는 아직 AXI 주변장치에 연결되지 않음.
- Vitis soc04_memory_map Application ELF Build 성공, FPGA 다운로드 및 Debug 진입 확인.
- 최종 WATCH: stage=5, addr_0=0x00001460; bram_word[0]=0x11111111, [1]=0xA5A5A5A5, [2]=0x33333333, [3]=0x44444444; read_1=0xA5A5A5A5.
- 쓰기 → 읽기 → 동일 주소 재기록 → 변경값 재확인 성공.

## 판정 경계
- 32비트 배열의 후속 요소 주소는 addr_0와 4바이트 요소 크기에 근거해 계산; 모든 주소를 WATCH로 실측한 것으로 표기하지 않음.
- 본문 SVG는 설명용 구조도이며 실제 Vivado GUI 캡처가 아님.
- FPGA AXI MMIO 접근 및 Timer 타이밍 검증은 04장 범위 밖.
