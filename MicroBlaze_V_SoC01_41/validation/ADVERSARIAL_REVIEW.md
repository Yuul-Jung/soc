# MicroBlaze V 원본 대조·실행 검토

기준일: 2026-10-16. 기존 41장·목차·그림 슬롯·화면 틀을 유지했다.

## 아직 실행하지 않은 항목

- MicroBlaze V용 실제 생성 BSP·도구 체인으로 컴파일·링크·ELF 실행.
- Vivado 합성·배치배선·타이밍·전력·CDC 보고서 생성.
- AMD XPM 라이브러리 시뮬레이션, SVA·기능 커버리지 시험.
- Basys3의 JTAG 다운로드·UART·인터럽트·메모리·NPU 보드 실행.

시뮬레이션 PASS는 제공된 자극·기대값 범위의 결과다. 전체 입력 공간이나 실제 보드 동작의 보증으로 확장하지 않는다.
