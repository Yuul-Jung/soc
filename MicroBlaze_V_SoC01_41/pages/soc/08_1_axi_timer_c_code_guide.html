CODE 01

프로그램 전체 흐름 — Timer가 시간을 세고 CPU가 LED를 바꾼다

Timer가 FPGA 내부에서 스스로 100 MHz Clock을 세고, MicroBlaze V CPU가 타이머 만료를 반복 확인합니다. 만료되면 기존 AXI GPIO에 LED0 값을 기록합니다.

100 MHz Clock → AXI Timer0(0.5초마다 만료) → MicroBlaze V의 Polling → AXI GPIO → LED0 반전
쉽게 말하면

Timer는 시계, CPU는 시계를 확인하는 사람, AXI GPIO는 LED 스위치입니다. 08장에서는 인터럽트가 아니라 반복 확인을 합니다.

Timer IPCPU가 가만히 있어도 카운트 진행
MicroBlaze V만료 표시를 반복 읽음
AXI GPIOLED0 ON/OFF 출력

핵심

Header(헤더)는 이미 구현된 Driver(드라이버, 장치 제어 코드)의 함수와 자료형을 사용할 수 있도록 선언을 가져옵니다. 헤더 자체가 주변장치를 실행하는 것은 아닙니다.

CODE 03

상수 — 0번 Timer, 1번 GPIO 채널, LED0 한 비트

/* SoC08: Timer0 0.5초 Polling, 기존 AXI GPIO LED0 출력 */
#define TIMER0                 0U
#define GPIO_LED_CHANNEL       1U
#define LED0_MASK              0x00000001U

/* 100 MHz × 0.5 s = 50,000,000 clocks, PG079: TLR + 2 */
#define TIMER_RESET_VALUE      (50000000U - 2U)
한 줄씩 읽기

TIMER0은 AXI Timer 안의 첫 번째 카운터를 뜻합니다. GPIO_LED_CHANNEL은 GPIO의 채널 1이고, LED0_MASK의 최하위 1비트만 LED0를 대상으로 삼습니다. 뒤의 U는 부호 없는 정수 상수라는 의미입니다.

100 MHz → 1 Clock은 10 ns → 0.5초에 50,000,000번 Clock
PG079 감소계수 Generate Mode: (TLR0 + 2) × 10 ns → TLR0는 49,999,998

TIMER_RESET_VALUE의 값은 49,999,998 = 0x02FAF07E입니다. LED0를 0.5초마다 한 번씩 반전시키므로, 켜짐→꺼짐→다시 켜짐의 전체 주기는 약 1초입니다.

CODE 04

CPU가 찾는 주소 — SDT 조건과 실제 Address Map

#ifndef SDT
#define TIMER_DEVICE_ID        XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID         XPAR_GPIO_0_DEVICE_ID
#else
#define TIMER_BASEADDR         XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR          XPAR_XGPIO_0_BASEADDR
#endif

#ifndef SDT는 SDT가 정의되지 않았을 때 Device ID(장치 식별번호)를 사용하고, #else는 SDT 환경에서 Base Address(기준 주소)를 사용하도록 컴파일 시 분기합니다. 실행 중에 두 경로를 번갈아 선택하는 코드가 아닙니다.

하드웨어실제 주소사용 목적
AXI Timer00x41C00000Timer 설정·현재값·만료 표시
AXI GPIO0x40000000LED0 출력
Local BRAM0x00000000프로그램·데이터 저장(16 KiB)

MicroBlaze V는 AXI4-Lite를 통해 Timer와 GPIO의 레지스터를 읽거나 씁니다. 코드의 Timer.BaseAddress는 이 Timer 주소를 가진 소프트웨어 객체의 필드입니다.

CPU와 메모리

CODE 06

init_gpio() — 기존 AXI GPIO를 사용할 준비

static int init_gpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

XGpio_Initialize()는 소프트웨어 Gpio 객체를 해당 GPIO 하드웨어 설정과 연결하여 사용할 준비를 합니다. 값으로 &Gpio를 전달하는 것은 객체의 주소를 함수에 넘긴다는 의미입니다.

코드 읽기

return으로 초기화 결과를 돌려줍니다. 실제 LED0를 켜고 끄는 작업은 뒤의 XGpio_DiscreteWrite()에서 이루어집니다.

CODE 07

init_timer() — AXI Timer 초기화와 자체 시험

static int init_timer(void)
{
    int status;
#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif
    if (status != XST_SUCCESS) return status;
    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) return status;

status 변수에 초기화 함수의 결과를 담습니다. XST_SUCCESS가 아니면 즉시 반환하여, 초기화 실패를 감춘 채 다음 코드로 진행하지 않습니다. XTmrCtr_SelfTest()는 Timer 드라이버의 기본 기능 검사를 요청합니다.

기억할 점

SelfTest가 성공해도 0.5초 실제 시간 정확도를 계측했다는 뜻은 아닙니다. 보드 LED 관찰과 Watch는 별도의 검증 단계입니다.

CODE 08

SetOptions → SetResetValue → Start — 타이머 작동 시작

    /* (유지) Down Count + Auto Reload, Interrupt 출력은 미사용 */
    XTmrCtr_SetOptions(&Timer, TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION);
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    XTmrCtr_Start(&Timer, TIMER0);
    return XST_SUCCESS;
}

XTC_DOWN_COUNT_OPTION은 감소 계수, XTC_AUTO_RELOAD_OPTION은 만료 후 다시 초기값으로 적재해 반복하는 방식입니다. 두 값은 비트 OR(|)로 결합합니다.

49,999,998 적재 → 카운터 감소 → 0 부근에서 만료 → 자동 재적재 → 다시 감소

XTmrCtr_SetOptions() 설정에는 Timer Interrupt Enable 옵션을 넣지 않았습니다. 08장은 Polling이고, CPU Interrupt 연결은 09장에서 다룹니다.

중요한 구분

Timer의 만료 상태 비트는 Polling에서도 사용하지만, 이것이 CPU에 외부 인터럽트를 연결했다는 뜻은 아닙니다.

CODE 09

clear_timer_expired() — 만료 표시를 지우는 이유

/* 만료 비트 T0INT는 1을 쓰면 0으로 지워진다. */
static void clear_timer_expired(void)
{
    u32 csr = XTmrCtr_GetControlStatusReg(Timer.BaseAddress, TIMER0);
    XTmrCtr_SetControlStatusReg(Timer.BaseAddress, TIMER0,
        csr | XTC_CSR_INT_OCCURED_MASK);
}

XTmrCtr_GetControlStatusReg()가 Timer0 제어·상태 레지스터 TCSR0를 읽습니다. XTC_CSR_INT_OCCURED_MASK에 해당하는 T0INT 비트는 Write-1-to-Clear(1을 써서 지우기) 방식이므로, csr | XTC_CSR_INT_OCCURED_MASK를 다시 기록하면 만료 표시를 지웁니다.

왜 지우나?

이 표시를 지우지 않으면 다음 반복문에서도 이전 만료를 새로운 만료로 착각할 수 있습니다. 상태를 지운 뒤 다음 만료를 기다립니다. 코드에 보이는 “INT”는 플래그 이름일 뿐, 08장에서 CPU ISR을 실행했다는 뜻이 아닙니다.

CODE 10

main() 초기화 — 실패하면 중단, LED0는 OFF에서 시작

int main(void)
{
    if (init_gpio() != XST_SUCCESS) return XST_FAILURE;
    if (init_timer() != XST_SUCCESS) return XST_FAILURE;

    /* LED0 초기 소등: 기존 AXI GPIO 채널 1 출력 */
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

먼저 init_gpio()와 init_timer()를 실행합니다. 둘 중 하나가 실패하면 XST_FAILURE를 반환합니다. 두 단계가 성공하면 XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state)로 LED0에 처음 0을 써서 OFF 상태로 시작합니다.

“LED0 OFF”는 현재 GPIO가 출력 채널로 구성되고 LED0 비트가 정상 연결된 기존 06~07장 하드웨어를 전제로 합니다.

CODE 11

while(1) — CPU가 Timer 값을 반복 읽는다

    while (1) {
        timer_value = XTmrCtr_GetValue(&Timer, TIMER0);
        if (XTmrCtr_IsExpired(&Timer, TIMER0)) {

while (1)은 계속 반복하라는 C 구문입니다. XTmrCtr_GetValue()는 현재 Timer0 값을 읽어 timer_value에 복사합니다. 그 다음 XTmrCtr_IsExpired()가 만료 상태 표시(T0INT)를 읽어 참인지 확인합니다.

CPU 내부에서

CPU가 AXI 버스를 통해 Timer 레지스터를 읽고 조건 분기 명령을 실행합니다. 카운터 감소 자체는 Timer 하드웨어가 합니다. 이 반복 확인이 바로 Polling(폴링)입니다.

CODE 12

만료 시 처리 — 37번이면 LED0가 켜지는 이유

        if (XTmrCtr_IsExpired(&Timer, TIMER0)) {
            clear_timer_expired();
            expire_count++;
            led_state ^= LED0_MASK;  /* 0 → 1 → 0 반복 */
            XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);
        }
    }
}

만료가 참이면 ① 플래그 지우기 → ② 만료 횟수 증가 → ③ LED0 상태 반전 → ④ GPIO에 새 상태 기록 순으로 동작합니다.

0 → 1첫 번째 만료
LED ON
1 → 0두 번째 만료
LED OFF
0 → 1세 번째 만료
LED ON
비트 연산 XOR 쉽게 읽기

led_state ^= LED0_MASK;는 현재 값의 최하위 비트와 1을 XOR한 값을 다시 저장합니다. 즉 LED0는 0 → 1 → 0을 반복하고 다른 LED 비트는 변경하지 않습니다.

CODE 13

실제 Basys3 Watch 결과 — 코드 실행과 값 연결

실제 Basys3에서 LED0 반복 점멸이 관찰되었고, 실행 후 Pause한 Debug Watch에 다음 값이 표시되었습니다.

변수실제 관측값코드가 한 일
timer_value0x028816E6XTmrCtr_GetValue()가 읽은 마지막 카운터 값
expire_count0x00000025 = 37expire_count++가 만료 처리 횟수를 누적
led_state0x000000010에서 시작해 홀수 37번 반전했으므로 LED0 ON
실제 확인: Debug 진입, Continue(F5), LED0 점멸 관찰, Pause 후 37회 만료 처리와 LED0 ON 확인.

이 결과는 Timer 기반 제어의 기능 검증입니다. 오실로스코프 등으로 정확한 0.5초 주기를 계측한 것은 아닙니다. Debug 중 Pause 위치가 Driver의 XTmrCtr_IsExpired() 함수 내부여도 이상은 아닙니다.

CODE 14

검증한 main.c 전체 — 코드를 한곳에서 복사

위에서 설명한 코드를 빠짐없이 모았습니다. 08장 실제 Debug 화면에서 확인된 변수명 GPIO_LED_CHANNEL, expire_count, timer_value, led_state에 맞추었습니다.

#include "xparameters.h"
#include "xtmrctr.h"
#include "xgpio.h"
#include "xstatus.h"
#include "xil_types.h"

/* SoC08: Timer0 0.5초 Polling, 기존 AXI GPIO LED0 출력 */
#define TIMER0                 0U
#define GPIO_LED_CHANNEL       1U
#define LED0_MASK              0x00000001U

/* 100 MHz × 0.5 s = 50,000,000 clocks, PG079: TLR + 2 */
#define TIMER_RESET_VALUE      (50000000U - 2U)

#ifndef SDT
#define TIMER_DEVICE_ID        XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID         XPAR_GPIO_0_DEVICE_ID
#else
#define TIMER_BASEADDR         XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR          XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;

/* Vitis Debug Watch로 확인할 변수 */
volatile u32 expire_count = 0U;
volatile u32 led_state = 0U;
volatile u32 timer_value = 0U;

static int init_gpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int init_timer(void)
{
    int status;
#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif
    if (status != XST_SUCCESS) return status;
    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) return status;

    /* (유지) Down Count + Auto Reload, Interrupt 출력은 미사용 */
    XTmrCtr_SetOptions(&Timer, TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION);
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    XTmrCtr_Start(&Timer, TIMER0);
    return XST_SUCCESS;
}

/* 만료 비트 T0INT는 1을 쓰면 0으로 지워진다. */
static void clear_timer_expired(void)
{
    u32 csr = XTmrCtr_GetControlStatusReg(Timer.BaseAddress, TIMER0);
    XTmrCtr_SetControlStatusReg(Timer.BaseAddress, TIMER0,
        csr | XTC_CSR_INT_OCCURED_MASK);
}

int main(void)
{
    if (init_gpio() != XST_SUCCESS) return XST_FAILURE;
    if (init_timer() != XST_SUCCESS) return XST_FAILURE;

    /* LED0 초기 소등: 기존 AXI GPIO 채널 1 출력 */
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    while (1) {
        timer_value = XTmrCtr_GetValue(&Timer, TIMER0);
        if (XTmrCtr_IsExpired(&Timer, TIMER0)) {
            clear_timer_expired();
            expire_count++;
            led_state ^= LED0_MASK;  /* 0 → 1 → 0 반복 */
            XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);
        }
    }
}
