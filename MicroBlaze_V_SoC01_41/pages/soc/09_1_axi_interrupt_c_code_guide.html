09장과 09.1장의 차이

09장 · Vivado/Vitis 따라하기→09.1장 · C 소스 이해→10장 · 통합

새 프로젝트를 생성하지 않습니다. 09장에서 사용할 C 코드의 의미를 설명하는 보조 학습 페이지입니다.

09장의 Vivado 하드웨어 구성, Vitis Build, FPGA Debug 및 LED0 점멸을 실기 검증했습니다. 아래 코드는 실제 SDT 기반 BSP 매크로를 기준으로 설명합니다. 정확한 0.5초 주기는 정밀 계측하지 않았습니다.

CODE 01

전체 흐름 — Timer 만료가 LED0를 바꾼다

AXI Timer 만료
  → AXI INTC의 인터럽트 요청
  → MicroBlaze V 인터럽트 진입
  → Timer 드라이버 Handler
  → TimerCallback: interrupt_count 증가
  → Main: AXI GPIO LED0 반전
코드 풀이 — 이 코드가 무엇을 하는가

08장에서는 CPU가 계속 Timer 상태를 읽었습니다. 09장에서는 Timer가 신호를 보내고 CPU가 등록된 처리 함수를 실행합니다.

CPU·하드웨어에서는?

중요한 구분: Timer의 interrupt 선과 CPU가 AXI 주소로 INTC 레지스터를 제어하는 경로는 서로 다른 연결입니다.

CODE 02

헤더 파일 — CPU와 주변장치용 도구

#include "xparameters.h"
#include "xtmrctr.h"
#include "xgpio.h"
#include "xstatus.h"
#include "xil_exception.h"
코드 풀이 — 이 코드가 무엇을 하는가

xparameters.h는 하드웨어에서 생성한 장치 이름과 주소를 담고, xtmrctr.h는 Timer 함수, xgpio.h는 LED GPIO 함수를 제공합니다. 직접 레지스터 주소를 외울 필요가 없습니다.

CPU·하드웨어에서는?

프로그램을 빌드할 때 실제 09장 XSA에서 생성된 BSP 헤더가 필요합니다. 이름이 다른 하드웨어의 헤더를 사용하면 안 됩니다.

CODE 03

Classic과 SDT — 어떤 초기화 경로를 쓸까?

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif
코드 풀이 — 이 코드가 무엇을 하는가

SDT 설정에서는 인터럽트 연결을 돕는 공통 함수를 쓰고, Classic 설정에서는 AXI INTC 드라이버를 직접 초기화합니다. 두 코드가 모두 실행되는 것이 아니라 빌드 설정에 따라 하나가 선택됩니다.

CPU·하드웨어에서는?

Vitis 2024.2의 실제 BSP에서 SDT 정의 여부를 확인하고, xparameters.h의 장치 ID·주소·인터럽트 번호를 대조합니다.

CODE 04

Timer 초기값 — 100 MHz에서 약 0.5초

#define TIMER0             0U
#define LED_CHANNEL        1U
#define TIMER_RESET_VALUE  49999998U
코드 풀이 — 이 코드가 무엇을 하는가

TIMER0는 첫 번째 타이머, LED_CHANNEL은 GPIO 첫 번째 채널, TIMER_RESET_VALUE는 08장 실습에서 사용한 값 49,999,998을 의미합니다.

CPU·하드웨어에서는?

100 MHz 클록의 한 주기는 10 ns입니다. 5천만 클록에 해당하는 간격이 약 0.5초입니다. 이는 설정상 값이고 실제 정밀 계측 결과는 아닙니다.

CODE 05

전역 변수와 volatile — 사건을 기억한다

volatile u32 interrupt_count = 0U;
volatile u32 timer_event = 0U;
volatile u32 led_state = 0U;
코드 풀이 — 이 코드가 무엇을 하는가

interrupt_count는 인터럽트가 몇 번 발생했는지 기억합니다. timer_event는 Main에 처리할 일이 생겼음을 알리고, led_state는 LED0가 켜진 상태인지 기록합니다.

CPU·하드웨어에서는?

volatile은 ISR과 Main이 공유하는 값의 메모리 접근을 컴파일러가 임의로 없애지 않도록 돕습니다. 다만 경쟁 상태까지 자동으로 해결하지는 않습니다.

CODE 06

TimerCallback — ISR은 사건만 표시한다

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
    timer_event = 1U;
}
코드 풀이 — 이 코드가 무엇을 하는가

Timer가 만료될 때 드라이버가 호출하는 사용자 Callback입니다. (void)는 사용하지 않는 인자에 대한 경고를 피하는 표현입니다. LED를 직접 쓰지 않고 발생 횟수와 이벤트만 기록합니다.

CPU·하드웨어에서는?

CPU는 메인 프로그램을 잠시 중단하고 인터럽트 처리를 수행합니다. Timer 드라이버 내부에서 원인 비트 처리 후 이 Callback이 호출됩니다.

CODE 07

InitGpio — LED 하드웨어 접근 준비

status = XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
/* SDT 설정에서는 GPIO_BASEADDR를 사용 */
코드 풀이 — 이 코드가 무엇을 하는가

XGpio_Initialize()는 GPIO 드라이버가 어떤 장치를 사용할지 설정합니다. 실제 코드에서는 Classic일 때 장치 ID를, SDT일 때 Base Address를 사용합니다.

CPU·하드웨어에서는?

GPIO는 이미 06장에서 검증한 AXI GPIO 하드웨어입니다. 09장은 새로운 LED 회로를 만들지 않습니다.

CODE 08

InitTimer — 주기와 인터럽트 옵션 준비

XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
XTmrCtr_SetOptions(&Timer, TIMER0,
    XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION |
    XTC_INT_MODE_OPTION);
XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
코드 풀이 — 이 코드가 무엇을 하는가

SetHandler는 사용자 Callback을 등록하고, SetOptions는 감소 계수·자동 재적재·인터럽트 모드를 사용하도록 설정합니다. SetResetValue는 08장과 같은 초기값을 넣습니다.

CPU·하드웨어에서는?

주기가 끝나면 Timer는 다시 설정된 값부터 계수를 시작합니다. XTC_INT_MODE_OPTION이 누락되면 기대한 Timer 인터럽트가 발생하지 않을 수 있습니다.

CODE 09

SetupInterruptSystem — Timer와 CPU 처리 경로 연결

XIntc_Connect(&Intc, TIMER_INTR_ID,
    (XInterruptHandler)XTmrCtr_InterruptHandler, &Timer);
XIntc_Enable(&Intc, TIMER_INTR_ID);
Xil_ExceptionRegisterHandler(XIL_EXCEPTION_ID_INT,
    (Xil_ExceptionHandler)XIntc_InterruptHandler, &Intc);
코드 풀이 — 이 코드가 무엇을 하는가

Classic 경로에서 Timer Handler를 인터럽트 번호에 연결한 뒤 활성화합니다. CPU는 먼저 INTC Handler를 실행하고, INTC Handler가 Timer Handler를 호출합니다.

CPU·하드웨어에서는?

SDT라면 XSetupInterruptSystem()으로 유사한 경로를 구성합니다. 실제 코드의 두 분기는 컴파일 때 분리됩니다.

CODE 10

Main Loop — 이벤트를 받고 LED0를 반전한다

XTmrCtr_Start(&Timer, TIMER0);
while (1) {
    if (timer_event != 0U) {
        timer_event = 0U;
        led_state ^= 1U;
        XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
    }
}
코드 풀이 — 이 코드가 무엇을 하는가

Timer를 시작한 뒤 Main은 새로운 이벤트가 기록되었는지 확인합니다. 이벤트가 있으면 지우고 led_state의 최하위 비트를 뒤집은 다음 GPIO에 보냅니다.

CPU·하드웨어에서는?

08장은 Timer의 하드웨어 상태 레지스터를 반복 읽고, 09장은 ISR이 남긴 소프트웨어 이벤트를 확인합니다. 이벤트 플래그 방식은 처리 중 다수 이벤트가 겹칠 경우 개수를 보존하지 못할 수 있습니다.

CODE 11

Watch — 실제로 무엇을 관찰할까?

interrupt_count  // 0x0000000C (12) → 0x00000023 (35)
timer_event     // 0x00000000 → 0x00000000
led_state       // 0x00000000 → 0x00000001
코드 풀이 — 이 코드가 무엇을 하는가

실행 중 Debug Watch에서 세 변수를 확인합니다. 인터럽트 수가 증가하는지, Main에서 이벤트를 처리하는지, LED0 상태가 반전하는지를 각각 확인합니다.

CPU·하드웨어에서는?

09장 실제 Vitis WATCH에서 인터럽트 횟수 12 → 35, LED 상태 0 → 1을 확인했습니다. timer_event 값이 두 화면 모두 0인 것은 Main에서 이벤트를 처리한 뒤일 수 있습니다.

실제 Watch 스크린샷은 09장 · Timer Interrupt 동작 검증에서 확인합니다.

CODE 12

main.c 전체 소스 — 한 번에 복사

09장 main.c 전체 코드입니다. SDT 방식의 Timer 주소 및 Interrupt Parent 매크로를 실제 BSP에서 확인했고, 해당 Application의 빌드와 Debug 실행도 성공했습니다.

#include "xparameters.h"     // 하드웨어 주소 및 장치 번호
#include "xtmrctr.h"         // AXI Timer 드라이버
#include "xgpio.h"           // AXI GPIO 드라이버
#include "xstatus.h"         // 성공/실패 반환값
#include "xil_exception.h"   // CPU 인터럽트 처리

#ifdef SDT
#include "xinterrupt_wrap.h" // SDT 기반 인터럽트 연결
#else
#include "xintc.h"          // Classic 기반 AXI INTC 드라이버
#endif

#define TIMER0             0U
#define LED_CHANNEL        1U
#define TIMER_RESET_VALUE  49999998U // 08장에서 사용한 값

#ifndef SDT
// 다음 이름은 실제 xparameters.h 확인 후 확정
#define TIMER_DEVICE_ID    XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID     XPAR_GPIO_0_DEVICE_ID
#define INTC_DEVICE_ID     XPAR_INTC_0_DEVICE_ID
#define TIMER_INTR_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#else
// 다음 주소 매크로 역시 실제 BSP를 확인
#define TIMER_BASEADDR     XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR      XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;
#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U; // 발생한 인터럽트 횟수
volatile u32 timer_event = 0U;     // Main에 전달할 이벤트
volatile u32 led_state = 0U;       // LED0 상태

// Timer 드라이버에서 호출하는 사용자 Callback
static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
    timer_event = 1U;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;
#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif
    if (status != XST_SUCCESS) return XST_FAILURE;

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) return XST_FAILURE;

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(&Timer, TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION | XTC_INT_MODE_OPTION);
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;
#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) return XST_FAILURE;
    status = XIntc_Connect(&Intc, TIMER_INTR_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler, &Timer);
    if (status != XST_SUCCESS) return XST_FAILURE;
    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) return XST_FAILURE;
    XIntc_Enable(&Intc, TIMER_INTR_ID);
    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler, &Intc);
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(&Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId, Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY);
    if (status != XST_SUCCESS) return XST_FAILURE;
#endif
    return XST_SUCCESS;
}

int main(void)
{
    if (InitGpio() != XST_SUCCESS) return XST_FAILURE;
    if (InitTimer() != XST_SUCCESS) return XST_FAILURE;
    if (SetupInterruptSystem() != XST_SUCCESS) return XST_FAILURE;

    XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        if (timer_event != 0U) {
            timer_event = 0U;
            led_state ^= 1U;
            XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
        }
    }
}
CPU·하드웨어에서는?

08장 Polling 프로그램과 구분되는 09장 Interrupt 프로그램입니다. FPGA에서 인터럽트 횟수 증가와 LED0 점멸을 확인했습니다.
