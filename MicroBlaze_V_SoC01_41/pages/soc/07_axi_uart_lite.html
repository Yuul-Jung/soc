Basys3 SoC + NPU · SoC 07

AXI UART Lite - PC 터미널 Echo 통신

Basys3의 FT2232HQ USB-UART Bridge와 AXI UART Lite를 연결하고, PC에서 입력한 문자를 MicroBlaze V가 RX FIFO에서 읽은 뒤 TX FIFO로 다시 전송한다. Memory Map, AXI4-Lite, FIFO, UART 직렬 통신이 하나의 실습으로 연결된다.

AXI UART Lite115200 8N1RX/TX FIFOPollingB18 / A18Echo

PC → FPGA

터미널 문자가 B18 RX로 들어온다.

MicroBlaze V

RX FIFO를 읽고 같은 Byte를 TX FIFO에 쓴다.

FPGA → PC

A18 TX를 통해 같은 문자가 터미널로 돌아온다.

SECTION 13

RX FIFO

RX FIFO는 16-entry이며 수신된 Character를 저장한다. 8-bit 설정에서는 유효 Data가 bit [7:0]에 들어온다.

PC Character → Serial RX → RX Control → RX FIFO → AXI Read → MicroBlaze V
RX FIFO가 비어 있을 때 직접 Read Transaction을 발행하면 PG142 기준 SLVERR가 발생할 수 있다. Driver의 Blocking Receive 함수는 Data가 들어올 때까지 기다린 뒤 읽는다.
SECTION 14

TX FIFO

TX FIFO도 16-entry이며 CPU가 전송할 Byte를 쓴다.

MicroBlaze V → AXI Write → TX FIFO → TX Control → Serial TX → PC
TX FIFO가 Full일 때 직접 Write하면 SLVERR가 발생할 수 있다. XUartLite_SendByte()는 FIFO가 쓸 수 있을 때까지 확인한 뒤 1 Byte를 전송한다.

SECTION 19

Echo 프로그램

아래 코드는 이번 실습을 위해 작성한 교육용 Polling Echo 코드이며, Base Address Macro의 Classic/SDT 구분은 AMD 공식 low-level example과 동일한 방식이다.

#include "xparameters.h"
#include "xuartlite_l.h"
#include "xil_types.h"

/*
 * SoC 07 - AXI UART Lite Polling Echo
 *
 * Hardware setting:
 *   Baud Rate : 115200
 *   Data Bits : 8
 *   Parity    : None
 *   Stop Bit  : 1
 *
 * PC terminal:
 *   115200 8N1
 *   Flow control : None
 *   Local echo   : Off
 */

#ifndef SDT
#define UARTLITE_BASEADDR XPAR_UARTLITE_0_BASEADDR
#else
#define UARTLITE_BASEADDR XPAR_XUARTLITE_0_BASEADDR
#endif

volatile u8  last_rx  = 0U;
volatile u32 rx_count = 0U;
volatile u32 tx_count = 0U;

static void uart_puts(const char *text)
{
    while (*text != '\0') {
        XUartLite_SendByte(UARTLITE_BASEADDR, (u8)*text);
        tx_count++;
        text++;
    }
}

int main(void)
{
    /*
     * CTRL_REG bit1 = RX FIFO reset
     * CTRL_REG bit0 = TX FIFO reset
     * 0x03 : 두 FIFO를 모두 비운다.
     * Interrupt bit4는 0이므로 Polling 방식이다.
     */
    XUartLite_WriteReg(
        UARTLITE_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );

    uart_puts("\r\nAXI UART Lite Echo Ready\r\n");
    uart_puts("Type characters. Received data will be echoed.\r\n> ");

    while (1) {
        /* RX FIFO에 문자가 들어올 때까지 Blocking 대기 */
        last_rx = XUartLite_RecvByte(UARTLITE_BASEADDR);
        rx_count++;

        /* 받은 1 Byte를 그대로 PC로 다시 전송 */
        XUartLite_SendByte(UARTLITE_BASEADDR, last_rx);
        tx_count++;
    }

    return 0;
}

SECTION 21

Ubuntu moserial 설정 및 통신

moserial(모시리얼, 그래픽 시리얼 통신 프로그램)로 PC와 Basys3 간 UART 데이터를 송수신한다. 실제 UART 장치명은 PC마다 다르므로 먼저 확인한다.

  1. 장치 확인 및 moserial 실행

    # Basys3 연결 후 USB 시리얼 장치와 연결 경로 확인
ls -l /dev/serial/by-id/

# moserial 설치 (이미 설치되어 있으면 생략)
sudo apt install moserial

# moserial 그래픽 프로그램 실행
moserial

    ls -l /dev/serial/by-id/는 연결된 USB 시리얼 장치의 고유 이름과 실제 /dev/ttyUSB* 장치 경로를 표시한다. sudo apt install moserial은 프로그램 설치, moserial은 GUI 실행 명령이다. 연결 장치를 보고 해당 /dev/ttyUSB0 또는 /dev/ttyUSB1 등을 선택하며 번호를 임의로 고정하지 않는다.

  2. Port Setup(포트 설정)

    moserial의 Port Setup 화면에서 다음 항목을 지정한다.

    설정 항목값
    Device장치 확인 결과에 해당하는 실제 UART 포트, 예: /dev/ttyUSB1
    Baud Rate115200
    Data Bits8
    ParityNone
    Stop Bits1
    HandshakeNone (흐름 제어 없음)
    Read / Write둘 다 허용
    Echo received dataOff (PC가 받은 바이트를 다시 FPGA로 자동 전송하지 않음)

  3. Connect → ELF 실행 → 문자 송수신

    Connect로 포트를 연 다음 Received ASCII 화면을 표시한다. 그 상태에서 Vitis의 ELF를 실행하여 시작 메시지가 수신되는지 확인한다.

    moserial의 Outgoing 입력칸에 A를 입력하고, 전송 방식은 ASCII, 줄 종료는 No end로 선택한 다음 Send를 누른다. 그러면 추가 줄바꿈 없이 문자 A 1바이트만 전송한다.

    Sent ASCII에 전송 문자 A가 기록되고, Received ASCII에 FPGA를 거쳐 돌아온 문자 A가 표시되면 Echo 경로를 확인할 수 있다. 같은 방식으로 B, 1도 전송한다.

주의: moserial은 보낸 데이터(Sent ASCII)와 받은 데이터(Received ASCII)를 서로 다른 화면에 표시한다. 두 곳에 A가 나타나는 것은 정상이며 중복 Echo가 아니다. Echo received data를 켜면 FPGA의 Echo와 맞물려 데이터가 반복 송수신될 수 있으므로 반드시 끈다.

장치 접근 권한 오류가 나는 경우 현재 사용자의 dialout 그룹 가입 여부를 확인한다. 설정 변경은 실제 오류를 확인한 뒤 수행한다.

SECTION 22

FPGA Program → moserial Connect → ELF Run 순서로 진행한다. moserial의 Received ASCII에서 아래 시작 문자열을 확인한다.

이어서 moserial Outgoing에서 ASCII, No end를 설정한 후 A, B, 1을 각각 Send한다. 보낸 문자는 Sent ASCII, FPGA에서 되돌아온 문자는 Received ASCII에서 구분하여 확인한다.

AXI Transaction 추적

[RECEIVE] PC → B18(RsRx) → Serial RX → RX FIFO → AXI Read : Base + 0x00 → MicroBlaze V last_rx [ECHO TRANSMIT] MicroBlaze V last_rx → AXI Write : Base + 0x04 → TX FIFO → Serial TX → A18(RsTx) → PC Terminal

SoC 05의 AR/R Read와 AW/W/B Write가 UART FIFO 접근으로 실제 적용된다.

SECTION 26

AMD 공식 Example Design · 예제 설계

AMD PG142 Chapter 5의 공식 예제는 MicroBlaze V 없이 AXI Traffic Generator(AXI 트래픽 제너레이터, 시험용 AXI 접근 생성기)가 AXI UART Lite에 데이터를 기록하는 별도 설계이다.

  1. 공식 예제 열기

    Vivado에서 AXI UART Lite IP의 Open IP Example Design 기능을 선택한다. 원본 SoC 프로젝트와 분리된 별도 예제 프로젝트로 연다.

  2. 데이터 전송 경로 읽기

    ATG가 AXI4-Lite를 통해 TX FIFO에 ASCII 0x41을 쓴다. UART 송신 포트에서는 문자 A가 출력된다.

  3. 코드와 실제 설계 구분

    예제에는 <component_name>_exdes.vhd, clock_gen.vhd, atg_*.coe가 포함된다. 이 파일들은 공식 예제 생성 시 제공되는 것이며 이 교재에서 별도로 작성한 MicroBlaze 프로그램이 아니다.

범위: 공식 PG142 예제는 KC705 보드를 대상으로 설명한다. Basys3 핀 제약을 그대로 대입하거나 07장 성공 프로젝트를 교체하지 않는다.

Verilog 테스트벤치 전체 코드 펼쳐 보기
`timescale 1ns / 1ps

// SoC 07: Verilog-2001 self-checking AXI UART Lite IP testbench.
// Reference: AMD PG142 Figure 5-1 (example) and Figure 6-1 (test bench).
// (변경) VHDL exdes 대신 AXI-Lite BFM으로 실제 Xilinx UART Lite IP 직접 구동.
// (추가) 공식 TX 'A'(0x41) 검사 외에 RX 'B'(0x42)와 Echo를 검증.
// DUT: independent Vivado IP Catalog "axi_uartlite_0" (100 MHz, 115200 8N1).
// Not a complete MicroBlaze V software / Basys3 hardware simulation.

module tb_soc07_axi_uartlite;
  localparam integer CLOCK_NS = 10;
  localparam integer BAUD = 115200;
  localparam integer BIT_NS = (1000000000 + BAUD/2) / BAUD;
  reg clk = 0;
  always #(CLOCK_NS/2) clk = ~clk;
  reg resetn = 0;
  reg rx = 1;
  wire tx, interrupt;

  reg [3:0] awaddr = 0, araddr = 0;
  reg [31:0] wdata = 0;
  reg [3:0] wstrb = 4'hF;
  reg awvalid = 0, wvalid = 0, bready = 0;
  reg arvalid = 0, rready = 0;
  wire awready, wready, bvalid, arready, rvalid;
  wire [1:0] bresp, rresp;
  wire [31:0] rdata;

  // Generate Output Products for this IP in Vivado before simulation.
  axi_uartlite_0 dut (
    .s_axi_aclk(clk), .s_axi_aresetn(resetn),
    .s_axi_awaddr(awaddr), .s_axi_awvalid(awvalid), .s_axi_awready(awready),
    .s_axi_wdata(wdata), .s_axi_wstrb(wstrb),
    .s_axi_wvalid(wvalid), .s_axi_wready(wready),
    .s_axi_bresp(bresp), .s_axi_bvalid(bvalid), .s_axi_bready(bready),
    .s_axi_araddr(araddr), .s_axi_arvalid(arvalid), .s_axi_arready(arready),
    .s_axi_rdata(rdata), .s_axi_rresp(rresp),
    .s_axi_rvalid(rvalid), .s_axi_rready(rready),
    .rx(rx), .tx(tx), .interrupt(interrupt)
  );

  // AXI4-Lite write: AW and W VALID asserted simultaneously.
  // VALID is held until each channel's READY handshake.
  task axi_write;
    input [3:0] address;
    input [31:0] value;
    reg got_aw, got_w;
    begin
      @(negedge clk);
      awaddr=address; wdata=value;
      awvalid=1; wvalid=1; bready=0;
      got_aw=0; got_w=0;
      while (!got_aw || !got_w) begin
        @(posedge clk);
        if (awvalid && awready) got_aw=1;
        if (wvalid && wready) got_w=1;
        @(negedge clk);
        if (got_aw) awvalid=0;
        if (got_w) wvalid=0;
      end
      wait(bvalid === 1'b1);
      if (bresp !== 2'b00) begin
        $display("TEST FAILED AXI WRITE address=%h bresp=%b", address,bresp);
        $stop;
      end
      @(negedge clk); bready=1;
      @(posedge clk);
      @(negedge clk); bready=0;
    end
  endtask

  task axi_read;
    input [3:0] address;
    output [31:0] value;
    begin
      @(negedge clk);
      araddr=address; arvalid=1; rready=0;
      begin : await_ar
        forever begin
          @(posedge clk);
          if (arvalid && arready) disable await_ar;
        end
      end
      @(negedge clk); arvalid=0;
      wait(rvalid === 1'b1);
      if (rresp !== 2'b00) begin
        $display("TEST FAILED AXI READ address=%h rresp=%b",address,rresp);
        $stop;
      end
      value=rdata;
      @(negedge clk); rready=1;
      @(posedge clk);
      @(negedge clk); rready=0;
    end
  endtask

  // Send a PC-originated 8N1 frame into the UART Lite RX pin.
  task uart_send;
    input [7:0] value;
    integer k;
    begin
      @(negedge clk); rx=0; #(BIT_NS);
      for (k=0;k<8;k=k+1) begin rx=value[k]; #(BIT_NS); end
      rx=1; #(BIT_NS);
    end
  endtask

  // Sample DUT TX at each data-bit center: LSB first, then stop bit.
  task uart_expect;
    input [7:0] expected;
    reg [7:0] actual;
    integer k;
    begin
      @(negedge tx);
      #(BIT_NS + BIT_NS/2);
      for (k=0;k<8;k=k+1) begin
        actual[k]=tx; #(BIT_NS);
      end
      if (tx !== 1'b1 || actual !== expected) begin
        $display("TEST FAILED UART expected=%h actual=%h stop=%b",
                 expected,actual,tx);
        $stop;
      end
      $display("PASS UART TX = %h",actual);
    end
  endtask

  reg [31:0] status, data;
  reg rx_valid;
  integer i;
  initial begin
    $display("SoC07 AXI UART Lite Verilog testbench start");
    repeat(20) @(posedge clk);
    @(negedge clk); resetn=1;
    repeat(20) @(posedge clk);

    // CTRL_REG (+0x0C): reset RX FIFO and TX FIFO, interrupts disabled.
    axi_write(4'hC,32'h00000003);

    // PG142 Figure 6-1's ASCII 'A' UART TX objective.
    fork
      axi_write(4'h4,32'h00000041);
      uart_expect(8'h41);
    join

    // Extension: receive a serial 'B' and check RX FIFO through AXI.
    uart_send(8'h42);
    rx_valid=0;
    begin : poll_rx
      for (i=0;i<100;i=i+1) begin
        axi_read(4'h8,status);  // STATUS bit0: RX FIFO valid
        if (status[0] === 1'b1) begin
          rx_valid=1;
          disable poll_rx;
        end
      end
    end
    if (!rx_valid) begin
      $display("TEST FAILED RX FIFO timeout");
      $stop;
    end
    axi_read(4'h0,data);
    if (data[7:0] !== 8'h42) begin
      $display("TEST FAILED RX FIFO data=%h",data[7:0]);
      $stop;
    end
    $display("PASS UART RX = %h",data[7:0]);

    // Software-equivalent Echo by writing received byte into TX FIFO.
    fork
      axi_write(4'h4,data);
      uart_expect(8'h42);
    join
    $display("SOC07 VERILOG UARTLITE SELF-CHECK PASS");
    $finish;
  end

  initial begin
    #2000000;
    $display("TEST FAILED GLOBAL TIMEOUT");
    $stop;
  end
endmodule

위 문자열은 예상 정상 출력이다. 현재 이 환경에서는 Vivado 2024.2의 IP 생성 및 실제 RTL 시뮬레이션을 실행하지 않았으므로, 이 메시지를 실측 성공 기록으로 취급하지 않는다. 실제 Basys3의 PC↔MicroBlaze V Echo 역시 별도 실습 검증 대상이다.
SUMMARY

SoC 07 실습 확인 항목

  • AXI UART Lite를 MicroBlaze V AXI Master에 연결했다.
  • Baud 115200, Data 8, Parity None으로 설정했다.
  • UART RX를 B18, TX를 A18에 연결했다.
  • Address Editor에서 실제 UART Lite Base Address를 확인했다.
  • RX FIFO +0x00, TX FIFO +0x04, STATUS +0x08, CONTROL +0x0C를 구분한다.
  • RX/TX FIFO가 각각 16-character 깊이임을 이해한다.
  • Status bit0과 bit3의 의미를 이해한다.
  • FIFO Clear를 위해 Control bit1/bit0을 사용했다.
  • XSA와 Vitis Platform을 갱신했다.
  • moserial을 115200 8N1, Handshake None, Echo received data Off로 설정하고 Outgoing에서 No end로 1바이트를 전송했다.
  • PC 입력 Byte를 RX FIFO에서 읽고 TX FIFO로 다시 썼다.
  • 실제 보드 실행에서 Echo 결과를 확인했다.
