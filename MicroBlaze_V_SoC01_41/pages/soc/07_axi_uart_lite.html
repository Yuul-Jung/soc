Basys3 SoC + NPU · SoC 07

AXI UART Lite - PC 터미널 Echo 통신

Basys3의 FT2232HQ USB-UART Bridge와 AXI UART Lite를 연결하고, PC에서 입력한 문자를 MicroBlaze V가 RX FIFO에서 읽은 뒤 TX FIFO로 다시 전송한다. Memory Map, AXI4-Lite, FIFO, UART 직렬 통신이 하나의 실습으로 연결된다.

MicroBlaze V

RX FIFO를 읽고 같은 Byte를 TX FIFO에 쓴다.

FPGA → PC

A18 TX를 통해 같은 문자가 터미널로 돌아온다.

A · 핵심 이론

UART 데이터가 RX FIFO → MicroBlaze V → TX FIFO로 이동하는 원리와 주소 구조를 먼저 이해합니다.

이론 01

실습으로 연결한 UART 통신 흐름 · 8N1

Ubuntu moserial Outgoing │ USB-UART / FT2232HQ ▼ Basys3 B18 · UART_0_rxd → RX FIFO → AXI Read → MicroBlaze V │ Echo Basys3 A18 · UART_0_txd ← TX FIFO ← AXI Write ──────┘ │ USB-UART / FT2232HQ ▼ Ubuntu moserial Received ASCII

UART 8N1은 Start 1비트(0) → Data 8비트 → Parity 없음 → Stop 1비트(1) 형식입니다. Idle 상태의 RX/TX는 High(1)입니다. 115200 bit/s가 IP와 PC에서 일치해야 합니다.

이론 02

AXI UART Lite 내부 구조

AXI4-Lite 레지스터 접근과 직렬 RX/TX 신호 사이에서 각각 16문자 깊이의 RX/TX FIFO(피포, 먼저 들어온 데이터를 먼저 꺼내는 버퍼)가 동작합니다.

FIFO·Status·Control 레지스터와 Polling 상세 내용은 제목을 눌러 펼칩니다. 실습부터 진행해도 됩니다.

이론 심화 01

RX FIFO

상세 설명 및 공식 도표 펼치기

RX FIFO는 16-entry이며 수신된 Character를 저장한다. 8-bit 설정에서는 유효 Data가 bit [7:0]에 들어온다.

PC Character → Serial RX → RX Control → RX FIFO → AXI Read → MicroBlaze V
RX FIFO가 비어 있을 때 직접 Read Transaction을 발행하면 PG142 기준 SLVERR가 발생할 수 있다. Driver의 Blocking Receive 함수는 Data가 들어올 때까지 기다린 뒤 읽는다.
이론 심화 02

TX FIFO

상세 설명 및 공식 도표 펼치기

TX FIFO도 16-entry이며 CPU가 전송할 Byte를 쓴다.

MicroBlaze V → AXI Write → TX FIFO → TX Control → Serial TX → PC
TX FIFO가 Full일 때 직접 Write하면 SLVERR가 발생할 수 있다. XUartLite_SendByte()는 FIFO가 쓸 수 있을 때까지 확인한 뒤 1 Byte를 전송한다.

이론 심화 05

Polling · C Driver · AXI 트랜잭션

상세 설명 및 공식 도표 펼치기

Polling(폴링, CPU가 상태를 반복적으로 확인하는 방식)은 인터럽트 없이 UART 상태를 읽고 데이터가 준비됐을 때 FIFO를 접근합니다.

수신: STATUS +0x08 bit0 확인 → RX FIFO +0x00 읽기 → last_rx 송신: STATUS +0x08 bit3 확인 → TX FIFO +0x04 쓰기 초기화: CONTROL +0x0C에 0x03 쓰기 → RX/TX FIFO Clear
C 함수AXI 동작
XUartLite_RecvByte(Base)RX FIFO Valid Data 대기 → Base+0x00 Read
XUartLite_SendByte(Base, ch)TX FIFO Full 여부 확인 → Base+0x04 Write
XUartLite_WriteReg(..., 0x03)Base+0x0C Write → 두 FIFO 초기화

05장의 AXI4-Lite Read/Write가 07장에서 실제 UART 데이터 이동에 사용됩니다.

    Sources → Design Sources에 새 soc07_axi_uartlite.bd가 생성됐는지 확인합니다. BD·XDC의 실제 경로가 06장 원본 폴더를 가리키면 07장 프로젝트로 Copy File Into Project 등의 기능으로 독립 복사합니다. 불필요한 기존 BD는 Remove File from Project로만 정리합니다. Delete files from disk는 선택하지 않습니다.

화면 확인 현재 프로젝트는 soc07_axi_uartlite이며 편집할 Block Design은 soc07_axi_uartlite.bd입니다. Wrapper는 아직 만들지 않습니다.

실습 03

AXI UART Lite 통신 설정 · 115200 8N1

  1. Customize IP 열기

    axi_uartlite_0를 더블클릭합니다.

  2. 통신값 입력

    Baud Rate 115200, Data Bits 8, Parity None을 지정합니다. UART Lite의 Stop Bit는 1입니다. AXI CLK Frequency는 실제 연결된 시스템 클록을 기준으로 06장 설정 100 MHz와 일치하는지 확인합니다.

  3. OK 선택

    설정값을 확인하고 OK를 클릭합니다. PC 터미널도 동일한 115200 8N1을 사용합니다.

항목값

Baud Rate115200
Data Bits8
ParityNone
Stop Bits1 (고정)
AMD PG142 공식 GUI 그림에 표시된 9600은 원본 예제값이며, 07장에서는 반드시 115200으로 설정합니다. 실제 Vivado 화면과 위 항목명을 대조합니다.

화면 확인 IP 설정이 115200, 8비트, Parity 없음으로 표시됩니다.

실습 04

AXI · Clock · Reset 연결

  1. Run Connection Automation 실행

    Diagram에서 axi_uartlite_0/S_AXI를 확인합니다. 상단 Run Connection Automation에서 UART의 S_AXI만 선택하고, 기존 CPU M_AXI_DP의 AXI 경로를 사용합니다.

    기대 화면: 기존 axi_smc에서 axi_uartlite_0/S_AXI로 AXI 선이 연결됩니다.
  2. 기존 AXI GPIO 유지 확인

    microblaze_riscv_0/M_AXI_DP → axi_smc를 따라가며 06장 axi_gpio_0/S_AXI가 남아 있는지, UART가 별도 출력으로 분기하는지 확인합니다. 실제 화면에서 확인된 M01_AXI처럼 출력 번호는 Vivado Diagram 값에 따릅니다.

    주의: 06장 GPIO 연결을 해제하거나 SmartConnect를 중복 생성하지 않습니다.

    UART의 s_axi_aclk가 기존 100 MHz AXI Clock, s_axi_aresetn이 기존 Active-Low 주변장치 Reset과 연결되는지 확인합니다.

    기대 화면: AXI, 클록, 리셋 신호가 모두 연결되어 있습니다.

실습 05

UART RX/TX 외부 포트 생성

  1. 현재 UART_0 외부 인터페이스 확인

    앞선 07장 GUI에서 UART_0를 이미 만들었다면 그대로 사용합니다. 별도의 RsRx/RsTx 포트를 중복 생성하지 않습니다.

    기대 화면: UART 외부 인터페이스 하나에 수신 RX와 송신 TX가 포함됩니다.
  2. 신호 방향 확인

    Diagram에서 UART 인터페이스를 펼쳐 rx가 FPGA Input, tx가 FPGA Output인지 확인합니다. 개별 핀 방식이라면 rx/tx를 각각 Make External로 만든 후 하나씩 방향을 확인합니다.

  3. 저장·Wrapper 포트명 확인

    Ctrl+S로 BD를 저장한 뒤 Wrapper 생성 절에서 새 Wrapper를 생성하고, 최상위 모듈 선언의 실제 RX/TX 포트명을 적습니다.

    주의: UART_0 인터페이스명과 최상위 Verilog 포트명은 다를 수 있습니다. Wrapper 확인 전에는 XDC에 이름을 단정하지 않습니다.

Basys3 USB-UART 핀: FPGA RX는 B18, FPGA TX는 A18입니다. 근거: Digilent Basys-3 Master XDC.

실습 06

Design Sources · Wrapper 생성 · Top 지정

Wrapper(래퍼, Block Design을 최상위 FPGA 포트와 연결하는 HDL)는 UART IP와 외부 포트를 모두 만든 뒤 생성합니다.

  1. 새 Block Design 선택

    Sources → Design Sources에서 soc07_axi_uartlite.bd를 선택합니다.

  2. Create HDL Wrapper

    우클릭 → Create HDL Wrapper → Let Vivado manage wrapper and auto-update를 선택합니다.

  3. Set as Top

    생성된 soc07_axi_uartlite_wrapper를 우클릭 → Set as Top으로 지정합니다. Wrapper에 UART RX/TX와 06장 GPIO 포트가 모두 보이는지 확인합니다.

  4. 구 Wrapper 정리

    07장 복제본에 남은 soc06_axi_gpio_wrapper는 새 Wrapper 확인 후 필요 시 Remove File from Project로만 제거합니다. Delete files from disk는 선택하지 않습니다.

화면 확인 Top Module이 soc07_axi_uartlite_wrapper이며 BD·Wrapper·XDC가 06장 원본을 직접 수정하지 않는 독립 경로입니다.

실습 07

Basys3 UART 핀 XDC 추가

  1. 07장 XDC 열기

    Sources → Constraints에서 07장에 독립 복사된 XDC를 엽니다. Clock·Reset·GPIO 핀 제약은 유지합니다.

  2. Wrapper 포트 이름 확인

    Wrapper 생성 절에서 생성한 최상위 soc07_axi_uartlite_wrapper의 RX/TX 이름이 UART_0_rxd/UART_0_txd인지 확인합니다. 이 프로젝트는 UART_0 인터페이스를 외부화했습니다.

  3. UART 핀 두 줄 추가

    이번 07장 자동 생성 모듈과 Wrapper의 실제 UART 포트명은 UART_0_rxd와 UART_0_txd입니다. 아래 두 줄을 그대로 입력합니다.

    기대 화면: RX와 TX 핀이 한 개씩 지정되고, 기존 GPIO/Clock/Reset XDC는 변경되지 않습니다.
## UART RX: PC → FPGA · B18
set_property -dict { PACKAGE_PIN B18 IOSTANDARD LVCMOS33 } [get_ports UART_0_rxd]
## UART TX: FPGA → PC · A18
set_property -dict { PACKAGE_PIN A18 IOSTANDARD LVCMOS33 } [get_ports UART_0_txd]

실제 확인: 위 두 포트로 XDC를 수정한 후 07장 Bitstream Generation이 성공했고, Setup WNS +0.817 ns 및 타이밍 위반 0건이 확인됐습니다.

실습 08

Address Editor · UART 주소 할당

  1. Address Editor 열기

    Vivado Block Design 상단의 Address Editor 탭을 선택합니다.

  2. UART 주소 배치

    axi_uartlite_0/S_AXI가 Unassigned 상태이면 Assign All 또는 해당 세그먼트의 주소 할당 기능을 실행합니다.

  3. 주소 기록

    UART Lite에 표시되는 실제 Base Address와 High Address를 확인합니다. 기존 BRAM·GPIO 범위와 겹치지 않는지 확인합니다. 아래 값은 실제 07장 Address Editor와 Vitis xparameters.h에서 확인된 값입니다.

구분확인할 범위
Local BRAM0x00000000 ~ 0x00003FFF · 16 KiB 유지
AXI GPIO0x40000000 ~ 0x4000FFFF · 64 KiB

화면 확인 UART가 주소 공간에 배치되며 GPIO·BRAM과 충돌하지 않습니다.

실제 확인: AXI GPIO 0x40000000, AXI UART Lite 0x40600000, Local BRAM 16 KiB가 07장 실제 Address Editor에서 확인됐습니다. 보조 예제의 다른 주소를 적용하지 않습니다.

실습 09

Validate Design → Bitstream → XSA

  1. 설계 검증

    Block Design을 저장하고 Validate Design을 실행합니다. AXI·Clock·Reset 오류가 없는지 확인합니다.

  2. Output Products 준비

    필요하면 soc07_axi_uartlite.bd에서 Generate Output Products를 실행하고 새 Wrapper가 Top인지 확인합니다.

  3. Generate Bitstream

    Flow Navigator → Generate Bitstream을 실행합니다. 합성·구현·비트스트림 완료 메시지와 오류 여부를 확인합니다.

  4. Export Hardware

    File → Export → Export Hardware에서 Include bitstream을 선택하여 07장 하드웨어 파일 soc07_axi_uartlite.xsa를 내보냅니다. 파일이 실제 생성됐는지 확인합니다.

화면 확인 07장 Bitstream 생성이 완료되고 새 soc07_axi_uartlite.xsa가 저장됩니다.

실습 12

main.c · UART 문자 Echo 코드

Vitis 07장 Application의 src/main.c에 다음 전체 코드를 입력합니다. 원본 C 코드 보기.

#include "xparameters.h"
#include "xuartlite_l.h"
#include "xil_types.h"

/*
 * SoC 07 - AXI UART Lite Polling Echo
 *
 * Hardware setting:
 *   Baud Rate : 115200
 *   Data Bits : 8
 *   Parity    : None
 *   Stop Bit  : 1
 *
 * PC terminal:
 *   115200 8N1
 *   Flow control : None
 *   Local echo   : Off
 */

#ifndef SDT
#define UARTLITE_BASEADDR XPAR_UARTLITE_0_BASEADDR
#else
#define UARTLITE_BASEADDR XPAR_XUARTLITE_0_BASEADDR
#endif

volatile u8  last_rx  = 0U;
volatile u32 rx_count = 0U;
volatile u32 tx_count = 0U;

static void uart_puts(const char *text)
{
    while (*text != '\0') {
        XUartLite_SendByte(UARTLITE_BASEADDR, (u8)*text);
        tx_count++;
        text++;
    }
}

int main(void)
{
    /*
     * CTRL_REG bit1 = RX FIFO reset
     * CTRL_REG bit0 = TX FIFO reset
     * 0x03 : 두 FIFO를 모두 비운다.
     * Interrupt bit4는 0이므로 Polling 방식이다.
     */
    XUartLite_WriteReg(
        UARTLITE_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );

    uart_puts("\r\nAXI UART Lite Echo Ready\r\n");
    uart_puts("Type characters. Received data will be echoed.\r\n> ");

    while (1) {
        /* RX FIFO에 문자가 들어올 때까지 Blocking 대기 */
        last_rx = XUartLite_RecvByte(UARTLITE_BASEADDR);
        rx_count++;

        /* 받은 1 Byte를 그대로 PC로 다시 전송 */
        XUartLite_SendByte(UARTLITE_BASEADDR, last_rx);
        tx_count++;
    }

    return 0;
}
코드동작
XUartLite_WriteReg(..., 0x03)시작할 때 RX·TX FIFO 비우기
uart_puts()PC에 시작 안내 문자열 전송
XUartLite_RecvByte()문자 1바이트가 들어올 때까지 대기
XUartLite_SendByte()받은 1바이트를 그대로 송신

화면 확인 실제 xparameters.h의 UART 주소 Macro와 코드가 일치하고 main() 함수는 한 개만 있습니다.

AMD PG142 Chapter 5의 공식 예제는 MicroBlaze V 없이 AXI Traffic Generator(AXI 트래픽 제너레이터, 시험용 AXI 접근 생성기)가 AXI UART Lite에 데이터를 기록하는 별도 설계이다.

Verilog 테스트벤치 전체 코드 펼쳐 보기
`timescale 1ns / 1ps

// SoC 07: Verilog-2001 self-checking AXI UART Lite IP testbench.
// Reference: AMD PG142 Figure 5-1 (example) and Figure 6-1 (test bench).
// (변경) VHDL exdes 대신 AXI-Lite BFM으로 실제 Xilinx UART Lite IP 직접 구동.
// (추가) 공식 TX 'A'(0x41) 검사 외에 RX 'B'(0x42)와 Echo를 검증.
// DUT: independent Vivado IP Catalog "axi_uartlite_0" (100 MHz, 115200 8N1).
// Not a complete MicroBlaze V software / Basys3 hardware simulation.

module tb_soc07_axi_uartlite;
  localparam integer CLOCK_NS = 10;
  localparam integer BAUD = 115200;
  localparam integer BIT_NS = (1000000000 + BAUD/2) / BAUD;
  reg clk = 0;
  always #(CLOCK_NS/2) clk = ~clk;
  reg resetn = 0;
  reg rx = 1;
  wire tx, interrupt;

  reg [3:0] awaddr = 0, araddr = 0;
  reg [31:0] wdata = 0;
  reg [3:0] wstrb = 4'hF;
  reg awvalid = 0, wvalid = 0, bready = 0;
  reg arvalid = 0, rready = 0;
  wire awready, wready, bvalid, arready, rvalid;
  wire [1:0] bresp, rresp;
  wire [31:0] rdata;

  // Generate Output Products for this IP in Vivado before simulation.
  axi_uartlite_0 dut (
    .s_axi_aclk(clk), .s_axi_aresetn(resetn),
    .s_axi_awaddr(awaddr), .s_axi_awvalid(awvalid), .s_axi_awready(awready),
    .s_axi_wdata(wdata), .s_axi_wstrb(wstrb),
    .s_axi_wvalid(wvalid), .s_axi_wready(wready),
    .s_axi_bresp(bresp), .s_axi_bvalid(bvalid), .s_axi_bready(bready),
    .s_axi_araddr(araddr), .s_axi_arvalid(arvalid), .s_axi_arready(arready),
    .s_axi_rdata(rdata), .s_axi_rresp(rresp),
    .s_axi_rvalid(rvalid), .s_axi_rready(rready),
    .rx(rx), .tx(tx), .interrupt(interrupt)
  );

  // AXI4-Lite write: AW and W VALID asserted simultaneously.
  // VALID is held until each channel's READY handshake.
  task axi_write;
    input [3:0] address;
    input [31:0] value;
    reg got_aw, got_w;
    begin
      @(negedge clk);
      awaddr=address; wdata=value;
      awvalid=1; wvalid=1; bready=0;
      got_aw=0; got_w=0;
      while (!got_aw || !got_w) begin
        @(posedge clk);
        if (awvalid && awready) got_aw=1;
        if (wvalid && wready) got_w=1;
        @(negedge clk);
        if (got_aw) awvalid=0;
        if (got_w) wvalid=0;
      end
      wait(bvalid === 1'b1);
      if (bresp !== 2'b00) begin
        $display("TEST FAILED AXI WRITE address=%h bresp=%b", address,bresp);
        $stop;
      end
      @(negedge clk); bready=1;
      @(posedge clk);
      @(negedge clk); bready=0;
    end
  endtask

  task axi_read;
    input [3:0] address;
    output [31:0] value;
    begin
      @(negedge clk);
      araddr=address; arvalid=1; rready=0;
      begin : await_ar
        forever begin
          @(posedge clk);
          if (arvalid && arready) disable await_ar;
        end
      end
      @(negedge clk); arvalid=0;
      wait(rvalid === 1'b1);
      if (rresp !== 2'b00) begin
        $display("TEST FAILED AXI READ address=%h rresp=%b",address,rresp);
        $stop;
      end
      value=rdata;
      @(negedge clk); rready=1;
      @(posedge clk);
      @(negedge clk); rready=0;
    end
  endtask

  // Send a PC-originated 8N1 frame into the UART Lite RX pin.
  task uart_send;
    input [7:0] value;
    integer k;
    begin
      @(negedge clk); rx=0; #(BIT_NS);
      for (k=0;k<8;k=k+1) begin rx=value[k]; #(BIT_NS); end
      rx=1; #(BIT_NS);
    end
  endtask

  // Sample DUT TX at each data-bit center: LSB first, then stop bit.
  task uart_expect;
    input [7:0] expected;
    reg [7:0] actual;
    integer k;
    begin
      @(negedge tx);
      #(BIT_NS + BIT_NS/2);
      for (k=0;k<8;k=k+1) begin
        actual[k]=tx; #(BIT_NS);
      end
      if (tx !== 1'b1 || actual !== expected) begin
        $display("TEST FAILED UART expected=%h actual=%h stop=%b",
                 expected,actual,tx);
        $stop;
      end
      $display("PASS UART TX = %h",actual);
    end
  endtask

  reg [31:0] status, data;
  reg rx_valid;
  integer i;
  initial begin
    $display("SoC07 AXI UART Lite Verilog testbench start");
    repeat(20) @(posedge clk);
    @(negedge clk); resetn=1;
    repeat(20) @(posedge clk);

    // CTRL_REG (+0x0C): reset RX FIFO and TX FIFO, interrupts disabled.
    axi_write(4'hC,32'h00000003);

    // PG142 Figure 6-1's ASCII 'A' UART TX objective.
    fork
      axi_write(4'h4,32'h00000041);
      uart_expect(8'h41);
    join

    // Extension: receive a serial 'B' and check RX FIFO through AXI.
    uart_send(8'h42);
    rx_valid=0;
    begin : poll_rx
      for (i=0;i<100;i=i+1) begin
        axi_read(4'h8,status);  // STATUS bit0: RX FIFO valid
        if (status[0] === 1'b1) begin
          rx_valid=1;
          disable poll_rx;
        end
      end
    end
    if (!rx_valid) begin
      $display("TEST FAILED RX FIFO timeout");
      $stop;
    end
    axi_read(4'h0,data);
    if (data[7:0] !== 8'h42) begin
      $display("TEST FAILED RX FIFO data=%h",data[7:0]);
      $stop;
    end
    $display("PASS UART RX = %h",data[7:0]);

    // Software-equivalent Echo by writing received byte into TX FIFO.
    fork
      axi_write(4'h4,data);
      uart_expect(8'h42);
    join
    $display("SOC07 VERILOG UARTLITE SELF-CHECK PASS");
    $finish;
  end

  initial begin
    #2000000;
    $display("TEST FAILED GLOBAL TIMEOUT");
    $stop;
  end
endmodule
