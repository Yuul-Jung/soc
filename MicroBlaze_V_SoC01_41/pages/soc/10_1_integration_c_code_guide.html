10장과 10.1장의 차이

10장 · Vivado/Vitis 따라하기→10.1장 · C 코드 풀이→11장 · Register Map

10장에서 Local BRAM을 64 KiB로 확장한 하드웨어를 이용해 GPIO·UART Lite·Timer·INTC를 통합한 C 프로그램의 함수와 데이터 흐름을 살펴봅니다.

10장 Application은 64 KiB 링커 설정으로 ELF Build에 성공했고, Basys3에서 스위치 입력·UART LED14 제어·Timer LED15 점멸을 확인했습니다. Timer 약 0.5초 간격은 설정값 기준이며 별도 정밀 실측값은 아닙니다.

CODE 01

전체 흐름 — 네 IP를 한 프로그램에 연결

PC moserial ('1','0','r','h') → UART Lite RX FIFO → CPU Main Loop
SW[15:0] → AXI GPIO Ch2 → CPU Main Loop
Timer 0 만료 → AXI INTC → CPU ISR → interrupt_count 증가
CPU Main → SW[13:0] + UART LED14 + Timer LED15 → GPIO Ch1 → LED[15:0]
코드 풀이 — 이 코드가 무엇을 하는가

10장 Vivado 프로젝트는 09장 하드웨어를 복제해 Local BRAM을 16 KiB에서 64 KiB로 확장합니다. AXI GPIO·UART Lite·Timer·INTC의 연결과 주변장치 주소는 그대로 유지하며, 이 C 코드는 10장 XSA에서 생성한 Platform으로 실행합니다. Main은 스위치를 읽고 UART 명령을 처리하며 LED 출력 하나를 계산합니다. Timer Callback은 인터럽트 횟수만 증가시킵니다.

CPU·하드웨어에서는?

새 AXI IP를 추가하는 실습이 아닙니다. MicroBlaze V가 여러 기존 주변장치의 데이터를 한 프로그램에서 함께 사용합니다.

헤더 파일 — 주변장치 함수를 가져온다

#include "xparameters.h"
#include "xgpio.h"
#include "xuartlite_l.h"
#include "xtmrctr.h"
#include "xstatus.h"
#include "xil_types.h"
#include "xil_exception.h"

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif
코드 풀이 — 이 코드가 무엇을 하는가

xparameters.h에는 생성된 하드웨어 주소와 장치 이름이 담깁니다. xgpio.h는 스위치·LED, xuartlite_l.h는 UART FIFO, xtmrctr.h는 타이머, xintc.h·xinterrupt_wrap.h는 인터럽트 연결에 사용합니다.

CPU·하드웨어에서는?

09장 XSA로 만든 실제 BSP에서 해당 헤더와 매크로를 확인합니다. SDT 정의가 있으면 SDT 쪽 코드만, 없으면 Classic 코드만 컴파일합니다.

CODE 03

LED 역할 상수 — 비트 영역을 서로 겹치지 않게

#define GPIO_LED_CHANNEL        1U
#define GPIO_SW_CHANNEL         2U

#define SW_LED_MASK             0x00003FFFU
#define UART_LED_MASK           0x00004000U
#define HEARTBEAT_LED_MASK      0x00008000U

#define TIMER0                  0U
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)
코드 풀이 — 이 코드가 무엇을 하는가

SW_LED_MASK는 하위 14비트(LED0~13), UART_LED_MASK는 14번 비트, HEARTBEAT_LED_MASK는 15번 비트만 선택합니다. 같은 GPIO 레지스터를 여러 기능이 나눠 쓸 때 핵심이 되는 규칙입니다.

CPU·하드웨어에서는?

예를 들어 SW0만 ON이면 하위 영역은 0x0001이고, UART로 LED14를 켜면 0x4000 비트가 추가됩니다. LED15는 Timer 횟수의 홀짝으로 결정됩니다.

CODE 04

주소 매크로 — Classic과 SDT 비교

#ifndef SDT
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#define UART_BASEADDR           XPAR_UARTLITE_0_BASEADDR
#else
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define UART_BASEADDR           XPAR_XUARTLITE_0_BASEADDR
#endif
코드 풀이 — 이 코드가 무엇을 하는가

Classic 경로는 XPAR_GPIO_0_DEVICE_ID처럼 장치 ID로 드라이버를 초기화합니다. SDT 경로는 GPIO·Timer의 Base Address를 사용합니다. UART는 두 경로 모두 Base Address를 통해 레지스터에 접근합니다.

CPU·하드웨어에서는?

주소와 장치 번호는 실제 Vivado Address Editor 및 Vitis BSP의 xparameters.h가 기준입니다. 실행에 사용한 10장 Vitis Platform의 xparameters.h를 기준으로 주소와 인터럽트 설정을 확인합니다.

CODE 05

객체와 변수 — 누가 어떤 상태를 기억할까?

static XGpio Gpio;
static XTmrCtr Timer;

#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U;
volatile u32 switch_value    = 0U;
volatile u32 led_state       = 0U;
volatile u8  last_uart_rx    = 0U;

static u32 uart_led_state = 0U;
코드 풀이 — 이 코드가 무엇을 하는가

Gpio와 Timer는 드라이버 객체입니다. interrupt_count는 ISR이 증가시키는 값, switch_value는 최근 스위치 입력, led_state는 실제 GPIO에 쓴 마지막 값, last_uart_rx는 마지막 받은 문자입니다. uart_led_state는 LED14 명령 상태만 저장합니다.

CPU·하드웨어에서는?

volatile은 ISR과 Main 사이에서 공유되는 값에 대한 컴파일러 접근 최적화를 제한합니다. volatile만으로 동시 접근 경쟁을 완전히 방지하지는 않습니다.

CODE 06

UartPutChar·UartPutString — 글자 보내기

static void UartPutChar(u8 ch)
{
    XUartLite_SendByte(UART_BASEADDR, ch);
}

static void UartPutString(const char *text)
{
    while (*text != '\0') {
        UartPutChar((u8)*text);
        text++;
    }
}
코드 풀이 — 이 코드가 무엇을 하는가

UartPutChar는 UART 송신 레지스터에 한 바이트를 보냅니다. UartPutString은 문자열의 끝 문자 '\0'이 나올 때까지 한 글자씩 전송합니다.

CPU·하드웨어에서는?

CPU가 UART Lite의 TX FIFO에 바이트를 쓰면 UART 하드웨어가 비트를 순서대로 전송합니다. SendByte가 송신 공간을 기다리는 동안 CPU가 짧게 대기할 수 있습니다.

CODE 07

16진수 출력 — 4비트 묶음을 문자로 바꾼다

static void UartPutHexNibble(u8 value)
{
    value &= 0x0FU;

    if (value < 10U) {
        UartPutChar((u8)('0' + value));
    } else {
        UartPutChar((u8)('A' + (value - 10U)));
    }
}

static void UartPutHex16(u16 value)
{
    int shift;

    for (shift = 12; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void UartPutHex32(u32 value)
{
    int shift;

    for (shift = 28; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}
코드 풀이 — 이 코드가 무엇을 하는가

UartPutHexNibble은 하위 4비트를 0~9 또는 A~F 문자로 바꿉니다. UartPutHex16은 16비트 수를 네 글자, UartPutHex32는 32비트 수를 여덟 글자 16진수로 출력합니다.

CPU·하드웨어에서는?

16진수 한 글자는 4비트입니다. 따라서 16비트 스위치·LED 값은 4글자이고 인터럽트 횟수 32비트는 8글자로 나타냅니다.

CODE 08

PrintHelp·PrintStatus — PC 터미널에 안내하기

static void PrintHelp(void)
{
    UartPutString("\r\nCommands\r\n");
    UartPutString("  1 : LED14 ON\r\n");
    UartPutString("  0 : LED14 OFF\r\n");
    UartPutString("  r : Read status\r\n");
    UartPutString("  h : Help\r\n");
}

static void PrintStatus(void)
{
    UartPutString("\r\nSW=0x");
    UartPutHex16((u16)switch_value);
    UartPutString(" LED=0x");
    UartPutHex16((u16)led_state);
    UartPutString(" IRQ=0x");
    UartPutHex32(interrupt_count);
    UartPutString("\r\n");
}
코드 풀이 — 이 코드가 무엇을 하는가

h 명령이면 1·0·r·h 안내를, r 명령이면 현재 스위치 값·LED 값·인터럽트 횟수를 출력합니다. 각 값 앞에 SW=0x, LED=0x, IRQ=0x를 붙여 구분합니다.

CPU·하드웨어에서는?

r 응답은 PrintStatus를 호출하는 순간에 Main이 읽고 보유한 값의 표시입니다. 출력 중 스위치나 카운터가 바뀔 수 있으므로 시점이 완전히 동일한 원자적 스냅샷은 아닙니다.

CODE 09

TimerCallback — 인터럽트에서는 카운터만 증가

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
}
코드 풀이 — 이 코드가 무엇을 하는가

타이머가 만료되면 Timer 드라이버 Handler가 이 Callback을 실행합니다. 사용하지 않는 인자는 (void)로 처리하고 interrupt_count++만 수행합니다.

CPU·하드웨어에서는?

Main Loop가 UART 송신 중이어도 Timer 인터럽트가 활성화되어 있으면 CPU는 잠시 인터럽트 처리를 실행하고 원래 프로그램으로 돌아갑니다.

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}
코드 풀이 — 이 코드가 무엇을 하는가

XGpio_Initialize 함수에 장치 ID 또는 Base Address를 전달하여 기존 GPIO IP를 사용할 준비를 합니다. 이 예제는 Channel 1 LED 출력과 Channel 2 스위치 입력을 전제로 합니다.

CPU·하드웨어에서는?

실제 AXI GPIO IP가 두 채널로 설정되어 있어야 합니다. 코드만으로 하드웨어의 GPIO 채널 개수를 바꿀 수는 없습니다.

CODE 11

InitTimer — 08장 설정에 인터럽트 사용

static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}
코드 풀이 — 이 코드가 무엇을 하는가

Timer를 초기화하고 SelfTest를 수행합니다. TimerCallback을 등록한 뒤 감소 계수·자동 재적재·인터럽트 모드를 설정하고 49,999,998을 Load 값으로 사용합니다.

CPU·하드웨어에서는?

설정상 Timer 입력 클록이 100 MHz일 때 만료 간격은 약 0.5초입니다. LED15 반복 점멸은 보드에서 확인했으며, 정확한 간격은 계측기로 측정한 값이 아닙니다.

CODE 12

SetupInterruptSystem — 인터럽트의 함수 경로 등록

static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}
코드 풀이 — 이 코드가 무엇을 하는가

Classic 구성은 AXI INTC 초기화 → Timer Handler 등록 → INTC 시작 → 해당 인터럽트 허용 → CPU 예외 등록과 활성화 순서입니다. SDT 구성은 XSetupInterruptSystem을 사용합니다.

CPU·하드웨어에서는?

Timer interrupt 신호는 AXI INTC와 CPU로 전달되고, CPU는 등록된 핸들러 함수를 실행합니다. 실제 인터럽트 ID와 CPU 예외 설정은 09장 실습에서 확정합니다.

CODE 13

InitUart — UART 수신·송신 FIFO 비우기

static void InitUart(void)
{
    /* RX/TX FIFO clear. UART interrupt remains disabled. */
    XUartLite_WriteReg(
        UART_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );
}
코드 풀이 — 이 코드가 무엇을 하는가

XUartLite_WriteReg로 AXI UART Lite의 Control Register에 0x03을 기록해 RX/TX FIFO를 초기화합니다. UART의 하드웨어 인터럽트는 별도로 활성화하지 않습니다.

CPU·하드웨어에서는?

UART에서 수신된 오래된 문자가 남지 않도록 초기화합니다. 09장의 Timer Interrupt와 달리 UART는 Main에서 데이터 유무를 직접 확인합니다.

CODE 14

HandleUartCommand — 문자 없으면 바로 돌아온다

static void HandleUartCommand(void)
{
    if (XUartLite_IsReceiveEmpty(UART_BASEADDR)) {
        return;
    }

    last_uart_rx = XUartLite_RecvByte(UART_BASEADDR);

    switch (last_uart_rx) {
    case '1':
        uart_led_state = UART_LED_MASK;
        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;
    }
}
코드 풀이 — 이 코드가 무엇을 하는가

XUartLite_IsReceiveEmpty가 참이면 즉시 return하여 스위치·LED 처리를 계속합니다. 문자가 있다면 RecvByte로 하나를 읽고 switch 문으로 1·0·r·h를 처리합니다.

CPU·하드웨어에서는?

Blocking Receive를 무조건 호출하는 코드와 달리 수신 문자가 없을 때 Main Loop가 멈추지 않습니다. 다만 출력 문자열을 전송하는 순간에는 잠시 기다릴 수 있습니다.

CODE 15

UART 명령 — 1·0·r·h를 어떻게 구분할까?

switch (last_uart_rx) {

        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;

코드 풀이 — 이 코드가 무엇을 하는가

문자 1은 LED14 비트를 켜도록 기억하고, 0은 끕니다. r은 현재 상태를 보여주고 h는 명령 안내를 보여줍니다. CR/LF는 건너뛰고 나머지 문자는 Unknown command로 처리합니다.

CPU·하드웨어에서는?

UART 명령은 led_state 전체를 직접 덮어쓰지 않습니다. LED14 전용 상태만 바꾸므로 SW·Timer가 담당하는 LED들과 충돌하지 않습니다.

CODE 16

UpdateLedOutput — 최종 LED 값을 한 번에 계산

static void UpdateLedOutput(void)
{
    u32 new_led_state;
    u32 heartbeat_state;

    if ((interrupt_count & 1U) != 0U) {
        heartbeat_state = HEARTBEAT_LED_MASK;
    } else {
        heartbeat_state = 0U;
    }

    new_led_state =
        (switch_value & SW_LED_MASK) |
        uart_led_state |
        heartbeat_state;

    if (new_led_state != led_state) {
        led_state = new_led_state;
        XGpio_DiscreteWrite(
            &Gpio,
            GPIO_LED_CHANNEL,
            led_state
        );
    }
}
코드 풀이 — 이 코드가 무엇을 하는가

인터럽트 횟수가 홀수면 LED15를 켭니다. switch_value의 하위 14비트, UART로 제어하는 LED14 상태, Timer의 LED15 상태를 비트 OR로 합쳐 new_led_state를 만듭니다. 최종값이 달라졌을 때만 GPIO에 기록합니다.

CPU·하드웨어에서는?

예를 들어 SW0=1, UART LED14 ON, IRQ 횟수 홀수라면 최종 LED 비트는 0xC001입니다. 이는 코드 계산 예시이지 보드 실측값이 아닙니다.

코드 풀이 — 이 코드가 무엇을 하는가

GPIO 초기화 → UART FIFO 초기화 → Timer 초기화 → 인터럽트 등록 → LED OFF → 준비 문자열 송신 → Timer 시작 순서입니다. 각 장치 초기화가 실패하면 실행을 계속하지 않습니다.

CPU·하드웨어에서는?

인터럽트가 발생하기 전에 관련 드라이버와 CPU 인터럽트 경로를 먼저 준비합니다.

코드 풀이 — 이 코드가 무엇을 하는가

Main Loop는 GPIO Channel 2에서 스위치를 읽고, UART 수신 명령을 확인한 다음 현재 인터럽트 카운터에 맞춰 하나의 LED 출력값을 계산합니다.

CPU·하드웨어에서는?

Timer의 인터럽트는 Main Loop와 별개 시점에 발생합니다. Main의 UART는 Polling이지만 Timer 만료를 계속 폴링하는 08장과 구분됩니다.

main.c 전체 원본 — 한 번에 복사

10장에서 실제 빌드하고 보드 동작을 확인한 통합 코드를 한 번에 제공합니다. 하드웨어 주소와 인터럽트 설정은 soc10_integration_platform의 BSP에서 확인합니다.

#include "xparameters.h"
#include "xgpio.h"
#include "xuartlite_l.h"
#include "xtmrctr.h"
#include "xstatus.h"
#include "xil_types.h"
#include "xil_exception.h"

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif

/*
 * SoC 10 - MicroBlaze V + GPIO + UART + Timer + AXI INTC Integration
 *
 * GPIO Channel 1 : LED[15:0] output
 * GPIO Channel 2 : SW[15:0] input
 *
 * LED ownership:
 *   LED[13:0] : SW[13:0] mirror
 *   LED14     : UART command control ('1' = ON, '0' = OFF)
 *   LED15     : Timer interrupt heartbeat
 *
 * UART : Polling, 115200 8N1
 * Timer: 100 MHz, 0.5 s interval, Down Count + Auto Reload + Interrupt
 * IRQ  : AXI Timer -> AXI INTC -> MicroBlaze V
 */

#define GPIO_LED_CHANNEL        1U
#define GPIO_SW_CHANNEL         2U

#define SW_LED_MASK             0x00003FFFU
#define UART_LED_MASK           0x00004000U
#define HEARTBEAT_LED_MASK      0x00008000U

#define TIMER0                  0U
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

#ifndef SDT
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#define UART_BASEADDR           XPAR_UARTLITE_0_BASEADDR
#else
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define UART_BASEADDR           XPAR_XUARTLITE_0_BASEADDR
#endif

static XGpio Gpio;
static XTmrCtr Timer;

#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U;
volatile u32 switch_value    = 0U;
volatile u32 led_state       = 0U;
volatile u8  last_uart_rx    = 0U;

static u32 uart_led_state = 0U;

static void UartPutChar(u8 ch)
{
    XUartLite_SendByte(UART_BASEADDR, ch);
}

static void UartPutString(const char *text)
{
    while (*text != '\0') {
        UartPutChar((u8)*text);
        text++;
    }
}

static void UartPutHexNibble(u8 value)
{
    value &= 0x0FU;

    if (value < 10U) {
        UartPutChar((u8)('0' + value));
    } else {
        UartPutChar((u8)('A' + (value - 10U)));
    }
}

static void UartPutHex16(u16 value)
{
    int shift;

    for (shift = 12; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void UartPutHex32(u32 value)
{
    int shift;

    for (shift = 28; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void PrintHelp(void)
{
    UartPutString("\r\nCommands\r\n");
    UartPutString("  1 : LED14 ON\r\n");
    UartPutString("  0 : LED14 OFF\r\n");
    UartPutString("  r : Read status\r\n");
    UartPutString("  h : Help\r\n");
}

static void PrintStatus(void)
{
    UartPutString("\r\nSW=0x");
    UartPutHex16((u16)switch_value);
    UartPutString(" LED=0x");
    UartPutHex16((u16)led_state);
    UartPutString(" IRQ=0x");
    UartPutHex32(interrupt_count);
    UartPutString("\r\n");
}

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}

static void InitUart(void)
{
    /* RX/TX FIFO clear. UART interrupt remains disabled. */
    XUartLite_WriteReg(
        UART_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );
}

static void HandleUartCommand(void)
{
    if (XUartLite_IsReceiveEmpty(UART_BASEADDR)) {
        return;
    }

    last_uart_rx = XUartLite_RecvByte(UART_BASEADDR);

    switch (last_uart_rx) {
    case '1':
        uart_led_state = UART_LED_MASK;
        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;
    }
}

static void UpdateLedOutput(void)
{
    u32 new_led_state;
    u32 heartbeat_state;

    if ((interrupt_count & 1U) != 0U) {
        heartbeat_state = HEARTBEAT_LED_MASK;
    } else {
        heartbeat_state = 0U;
    }

    new_led_state =
        (switch_value & SW_LED_MASK) |
        uart_led_state |
        heartbeat_state;

    if (new_led_state != led_state) {
        led_state = new_led_state;
        XGpio_DiscreteWrite(
            &Gpio,
            GPIO_LED_CHANNEL,
            led_state
        );
    }
}

int main(void)
{
    int status;

    status = InitGpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    InitUart();

    status = InitTimer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = SetupInterruptSystem();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    led_state = 0U;
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    UartPutString("\r\nSoC 10 Integrated System Ready\r\n");
    PrintHelp();

    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        switch_value = XGpio_DiscreteRead(
            &Gpio,
            GPIO_SW_CHANNEL
        );

        HandleUartCommand();
        UpdateLedOutput();
    }

    return XST_SUCCESS;
}
