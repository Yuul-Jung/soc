Basys3 SoC + NPU · SoC 08

AXI Timer - 0.5초 Polling과 LED Blink

100 MHz AXI Clock을 직접 세어 0.5초 간격을 만들고, Timer 만료를 MicroBlaze V가 Polling으로 확인해 AXI GPIO의 LED0를 반전한다. Clock → Counter → Register → Software → LED 동작이 하나의 경로로 연결된다.

AXI Timer100 MHz32-bit CounterDown CountAuto ReloadPolling

Timer

100 MHz Clock을 50,000,000회 세어 약 0.5초를 만든다.

CPU

Timer 만료 Flag를 Polling으로 확인한다.

LED

만료할 때마다 LED0를 반전해 약 1초 Blink 주기를 만든다.

SECTION 01

실습 목표

100 MHz Clock → AXI Timer → 0.5초 만료 → MicroBlaze V Polling → AXI GPIO → LED0 Toggle

LED0는 0.5초마다 상태가 바뀐다. 따라서 OFF 0.5초 → ON 0.5초 → OFF 0.5초로 반복되며 한 번의 완전한 ON/OFF Cycle은 약 1초이다.

07장 UART 통신을 실제 보드에서 검증한 뒤 진행합니다. 이 장의 LED 시간표는 실기 확인 이전에는 예상 결과입니다.

SECTION 02

기존 SoC에 Timer 추가

SoC 06의 AXI GPIO와 SoC 07의 AXI UART Lite는 그대로 유지하고 axi_timer_0만 추가한다.

MicroBlaze V │ ▼ SmartConnect ├─ AXI GPIO ──────▶ LED[15:0] ├─ AXI UART Lite ─▶ PC Terminal └─ AXI Timer │ └─ Polling으로 만료 상태 확인

Timer에는 별도의 외부 FPGA Pin이 필요하지 않는다.

SECTION 03

AXI Timer 내부 구조

AXI Timer는 AXI4-Lite Slave Interface와 두 개의 Timer/Counter Module을 가진다. 각 Timer는 Load Register, Counter Register, Control/Status Register를 갖는다.

MicroBlaze V의 Peripheral AXI 경로를 활성화하여 IP를 연결한다. 하드웨어 변경 후 XSA와 V용 Platform/BSP를 갱신하고 생성된 xparameters.h의 심볼을 사용한다.

SECTION 05

Clock와 Prescaler

PG079는 Timer Module의 Clock Rate가 s_axi_aclk이며 별도의 Prescaling을 하지 않는다고 설명한다. 현재 시스템 Clock은 100 MHz이므로 Timer도 100 MHz를 직접 센다.

100 MHz → 1 Clock = 10 ns → 100,000,000 Clocks = 1 s → 50,000,000 Clocks = 0.5 s

SECTION 07

08장 프로젝트 보존 · AXI Timer IP 추가

  1. 07장 성공본 복제

    07장 프로젝트가 실제 Echo까지 검증되면 File → Project → Save As로 08장 작업본을 만듭니다. 프로젝트명 예시는 soc08_axi_timer입니다. 최종 저장 위치는 GUI에서 확인합니다.

    주의: 07장 .xpr, .bd, XDC를 삭제하거나 이동하지 않습니다.
  2. 08장 Block Design 분리

    Sources → Design Sources에서 BD를 열고 필요한 경우 File → Save Block Design As로 별도 이름으로 저장합니다. 소스·제약이 07장 경로를 직접 참조하지 않는지 확인합니다.

  3. AXI Timer 추가

    Diagram의 + (Add IP) → AXI Timer를 검색해 더블클릭합니다.

    기대 화면: axi_timer_0가 생기고 GPIO/UART는 유지됩니다.
  4. Timer 기본 설정 확인

    axi_timer_0 더블클릭 → Timer/Counter 폭을 32-bit로 확인하고, Timer 0만 이번 코드에 사용합니다. 64-bit Cascade를 사용하지 않습니다. OK.

    주의: Interrupt 신호는 09장에서 연결합니다.
SECTION 08

AXI · Clock · Reset 연결

  1. AXI Slave만 연결

    상단 Run Connection Automation에서 axi_timer_0/S_AXI만 선택합니다. CPU M_AXI_DP의 기존 axi_smc를 재사용합니다.

  2. 분기 확인

    axi_gpio_0/S_AXI, axi_uartlite_0/S_AXI, axi_timer_0/S_AXI가 각각 CPU AXI 경로에 연결되었는지 선으로 확인합니다.

    기대 화면: 기존 주변장치 2개와 새 Timer 1개가 모두 AXI에 연결됩니다.
  3. Clock/Reset 확인

    axi_timer_0/s_axi_aclk는 기존 100 MHz AXI Clock에, s_axi_aresetn은 기존 Active-Low Peripheral Reset에 연결합니다. Timer interrupt는 이번 장에서 연결하지 않습니다.

SECTION 09

Address Editor · Timer 주소 할당

  1. Address Editor 열기

    Block Design의 Address Editor 탭을 클릭합니다.

  2. Timer 주소 할당

    axi_timer_0/S_AXI가 Unassigned이면 Assign All 또는 해당 행의 주소 할당 기능을 실행합니다. 이미 할당돼 있다면 무작정 재설정하지 않습니다.

  3. 주소 충돌 확인

    BRAM, 06장 GPIO, 07장 UART의 실제 Base/High Address와 Timer 범위를 비교합니다. 기존 배치는 유지하고 Timer 주소·Range를 기록합니다.

    기대 화면: Timer를 포함한 AXI 주소가 Assigned이며 충돌하지 않습니다.

보조 L05의 0x4003_0000은 별도 프로젝트 예시 주소입니다.

SECTION 13

0.5초 계산

PG079의 32-bit Down-count Generate Mode 식을 그대로 사용한다.

TIMING_INTERVAL = (TLR0 + 2) × AXI_CLOCK_PERIOD AXI_CLOCK_PERIOD = 10 ns 목표 시간 = 0.5 s = 500,000,000 ns 500,000,000 ns = (TLR0 + 2) × 10 ns TLR0 + 2 = 50,000,000 TLR0 = 49,999,998 = 0x02FAF07E

따라서 코드의 TIMER_RESET_VALUE는 49,999,998이다.

SECTION 14

Auto Reload

XTC_AUTO_RELOAD_OPTION을 사용하면 Counter가 만료된 뒤 Load Value를 다시 불러와 반복 Count한다.

SECTION 15

Polling 만료 확인

if (XTmrCtr_IsExpired(&Timer, TIMER0)) {
    clear_timer_expired();

    expire_count++;

    led_state ^= LED0_MASK;
    XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
}

XTmrCtr_IsExpired()는 TCSR0의 만료 Event Flag를 Polling한다. Interrupt 출력은 활성화하지 않는다.

SECTION 16

LED Toggle 구조

LED0 OFF : led_state = 0x00000000 ↓ 0.5 s LED0 ON : led_state = 0x00000001 ↓ 0.5 s LED0 OFF : led_state = 0x00000000 ↓ 반복

비트 XOR 연산 led_state ^= 0x1로 LED0만 반전한다.

SECTION 17

XDC 유지

AXI Timer 자체는 외부 Pin이 없다. LED 출력은 기존 SoC 06 AXI GPIO를 그대로 사용하므로 기존 Basys3 Switch/LED XDC를 유지한다.

Timer = 내부 IP · 신규 XDC 없음 → LED0 = 기존 AXI GPIO/XDC 사용

SECTION 19

Timer + GPIO 프로그램

아래 코드는 SoC 08 실습을 위해 작성한 교육용 코드이며 Timer Driver API는 AMD embeddedsw의 Polling Example과 현재 Driver 정의를 기준으로 사용한다.

#include "xparameters.h"
#include "xtmrctr.h"
#include "xgpio.h"
#include "xstatus.h"
#include "xil_types.h"

/*
 * SoC 08 - AXI Timer Polling + AXI GPIO LED Blink
 *
 * Timer clock : 100 MHz
 * Clock period: 10 ns
 *
 * Down-count Generate Mode:
 *   interval = (TLR0 + 2) * 10 ns
 *
 * 0.5 s:
 *   50,000,000 clocks
 *   TLR0 = 50,000,000 - 2
 *        = 49,999,998
 *        = 0x02FAF07E
 *
 * Timer expires every 0.5 s.
 * LED0 toggles at every expiration.
 * Therefore LED0 ON/OFF full cycle is about 1 s.
 */

#define TIMER0                  0U
#define LED_CHANNEL             1U
#define LED0_MASK               0x00000001U

#define TIMER_CLOCK_HZ          100000000U
#define TIMER_INTERVAL_MS       500U
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

#ifndef SDT
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#else
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;

volatile u32 led_state    = 0U;
volatile u32 expire_count = 0U;
volatile u32 timer_value  = 0U;

static int init_gpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int init_timer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return status;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return status;
    }

    /*
     * Polling Generate Mode:
     * - Down Count
     * - Auto Reload
     * - Interrupt output is NOT enabled
     */
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION
    );

    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    XTmrCtr_Start(&Timer, TIMER0);

    return XST_SUCCESS;
}

static void clear_timer_expired(void)
{
    u32 csr;

    /*
     * T0INT is Write-1-to-Clear.
     * Keep the current control bits and write 1 only to the event flag.
     */
    csr = XTmrCtr_GetControlStatusReg(Timer.BaseAddress, TIMER0);

    XTmrCtr_SetControlStatusReg(
        Timer.BaseAddress,
        TIMER0,
        csr | XTC_CSR_INT_OCCURED_MASK
    );
}

int main(void)
{
    int status;

    status = init_gpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = init_timer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    /* LED0 initially OFF */
    XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);

    while (1) {
        /* Debugger에서 현재 down-counter 값을 관찰할 수 있다. */
        timer_value = XTmrCtr_GetValue(&Timer, TIMER0);

        if (XTmrCtr_IsExpired(&Timer, TIMER0)) {
            clear_timer_expired();

            expire_count++;

            /* LED0 toggle */
            led_state ^= LED0_MASK;
            XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
        }
    }

    return XST_SUCCESS;
}

SECTION 24

AXI Transaction 추적

[초기 설정] MicroBlaze V → AXI Write → TLR0 = 49,999,998 → AXI Write → TCSR0 : Down + Auto Reload + Enable [반복 확인] MicroBlaze V → AXI Read → TCR0 / TCSR0 → 만료 확인 → AXI Write → TCSR0 Event Flag Clear → AXI Write → GPIO_DATA LED0 Toggle

Timer는 Clock을 Hardware에서 독립적으로 세지만, Polling에서는 CPU가 AXI Read를 반복하여 Event Flag를 확인한다.

SUMMARY

SoC 08 완료 판정 기준

  • 기존 AXI GPIO와 AXI UART Lite를 유지한 상태에서 AXI Timer를 추가했다.
  • AXI Timer가 AXI4-Lite Slave임을 이해한다.
  • Timer 0의 TCSR0, TLR0, TCR0 역할을 구분한다.
  • Timer Clock이 100 MHz이고 별도 Prescaler가 없음을 이해한다.
  • Generate Mode + Down Count + Auto Reload를 사용했다.
  • 0.5초에 필요한 TLR0가 49,999,998 = 0x02FAF07E임을 계산할 수 있다.
  • Interrupt Output을 사용하지 않고 Polling으로 만료를 확인했다.
  • T0INT가 Write-1-to-Clear임을 이해한다.
  • 0.5초마다 LED0를 Toggle한다.
  • LED의 전체 ON/OFF Cycle이 약 1초임을 이해한다.
  • Debugger에서 timer_value, expire_count, led_state를 확인했다.
  • 다음 장에서 Polling을 AXI Interrupt Controller 기반 Interrupt 구조로 변경할 준비가 되었다.

Vivado 검증 및 하드웨어 내보내기

  1. Validate Design: 오류 0건, Critical Warning 0건
  2. Create HDL Wrapper: soc08_axi_timer_wrapper.v 자동 생성, Top 지정; 포트 UART_0_rxd, UART_0_txd, btnC, clk, led_tri_o[15:0], sw_tri_i[15:0] 확인
  3. Generate Bitstream: 구현 타이밍 WNS +0.675 ns, WHS +0.035 ns, TNS/THS 0 ns; 사용자 타이밍 제약 충족
  4. Report Power: On-chip 약 0.200 W 예측, Confidence LOW — 실측값이 아님
  5. DRC: PDRC 관련 Warning 8건 관측 — 기능 검증 성공과 별도로 원인 점검 필요
  6. File → Export → Export Hardware: Include bitstream 선택, 실제 생성 파일 /home/jung/soc/hw/soc08_axi_timer/soc08_axi_timer_wrapper.xsa

Vitis 2024.2 Platform부터 ELF까지

  1. File → New Component → Platform에서 이름 soc08_axi_timer_platform, 위치 /home/jung/soc/sw 지정
  2. Hardware Design으로 위 XSA 선택, OS standalone, CPU microblaze_riscv_0 선택하여 Platform Build 성공
  3. 생성된 xparameters.h에서 XPAR_XTMRCTR_0_BASEADDR 0x41c00000, XPAR_XTMRCTR_0_CLOCK_FREQUENCY 0x05f5e100 확인(100 MHz)
  4. File → New Component → Application에서 soc08_axi_timer 생성, 08장 Platform 및 standalone_microblaze_riscv_0 선택; Empty Application에 main.c 작성
  5. Build 완료, soc08_axi_timer.elf 생성 확인; 편집기 진단 표시와 실제 컴파일 성공 여부는 구분
  6. launch.json 탭을 열어 08장 .bit, 08장 .elf, microblaze_riscv_0 확인한 후 Debug 실행
  7. Debug 일시정지 중에는 LED가 멈추므로 Continue (F5)로 재개. Basys3 LED0 반복 점멸을 실제 관찰
  8. 실행 후 Pause하여 Watch 변수 세 개의 실제 변경값을 검증
