SECTION 01이론

실습 목표 · 0.5초마다 LED0 반전

07장 UART Echo 성공 하드웨어에 AXI Timer만 추가합니다.

동작 경로
MicroBlaze V → AXI SmartConnect → AXI Timer 설정 · 만료 상태 폴링 → AXI GPIO → Basys3 LED0

100 MHz 타이머의 만료를 0.5초마다 확인하여 LED0를 반전시킵니다. LED가 켜졌다 꺼지는 전체 주기는 약 1초입니다. LED0 반복 점멸은 실제 보드에서 확인했으며, 정확한 0.5초 간격은 외부 계측기로 측정하지 않았습니다.

SECTION 03이론

AMD PG079 원문 · AXI Timer 내부 구조

기존 교재의 재작성 SVG를 제거하고 AMD 공식 원본의 위치와 문서 버전을 명확히 표기합니다.

AXI4-Lite(악시 포 라이트, 단일 레지스터 읽기·쓰기용 인터페이스)로 CPU가 Timer 레지스터를 설정하고 읽습니다. Counter는 CPU 코드가 매 순간 감소시키는 것이 아니라 s_axi_aclk에 따라 하드웨어에서 독립적으로 진행됩니다.

실제 Timer Base Address는 0x41C00000입니다. 예: TCSR0의 주소는 0x41C00000, TLR0는 0x41C00004입니다.

TCSR0의 주요 설정은 T0INT(bit 8, 만료 플래그), ENT0(bit 7, 카운터 동작), ENIT0(bit 6, 인터럽트 출력), LOAD0(bit 5, 값 적재), ARHT0(bit 4, 자동 재적재), UDT0(bit 1, 감소), MDT0(bit 0, Generate 모드)입니다. AMD TCSR0 전체 비트 원문

SECTION 05이론

0.5초를 만드는 카운트 값

실제 연결한 Timer의 AXI Clock은 100 MHz입니다.

100 MHz → 1 Clock = 10 ns
0.5 s ÷ 10 ns = 50,000,000 clocks
TLR0 = 50,000,000 − 2 = 49,999,998 = 0x02FAF07E

PG079의 Down-count Generate Mode에서는 TIMING_INTERVAL = (TLRx + 2) × AXI_CLOCK_PERIOD입니다. AMD PG079 · Generate Mode 원문

다음 단계에서는 32비트 Down Count + Auto Reload(오토 리로드, 자동 재적재) + Polling(폴링, CPU 반복 확인)을 사용합니다. Interrupt(인터럽트, 이벤트 알림 신호) 배선은 09장에서 진행합니다.

SECTION 18Vivado / Vitis 실습

main.c · 0.5초 Timer Polling 코드

하드웨어를 직접 세는 것은 Timer IP이며, CPU는 만료 상태를 확인해 LED를 변경합니다.

main.c 전체 코드
#include "xparameters.h"
#include "xtmrctr.h"
#include "xgpio.h"
#include "xstatus.h"
#include "xil_types.h"

/* SoC08: Timer0 0.5초 Polling, 기존 AXI GPIO LED0 출력 */
#define TIMER0                 0U
#define GPIO_LED_CHANNEL       1U
#define LED0_MASK              0x00000001U

/* 100 MHz × 0.5 s = 50,000,000 clocks, PG079: TLR + 2 */
#define TIMER_RESET_VALUE      (50000000U - 2U)

#ifndef SDT
#define TIMER_DEVICE_ID        XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID         XPAR_GPIO_0_DEVICE_ID
#else
#define TIMER_BASEADDR         XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR          XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;

/* Vitis Debug Watch로 확인할 변수 */
volatile u32 expire_count = 0U;
volatile u32 led_state = 0U;
volatile u32 timer_value = 0U;

static int init_gpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int init_timer(void)
{
    int status;
#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif
    if (status != XST_SUCCESS) return status;
    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) return status;

    /* (유지) Down Count + Auto Reload, Interrupt 출력은 미사용 */
    XTmrCtr_SetOptions(&Timer, TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION);
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    XTmrCtr_Start(&Timer, TIMER0);
    return XST_SUCCESS;
}

/* 만료 비트 T0INT는 1을 쓰면 0으로 지워진다. */
static void clear_timer_expired(void)
{
    u32 csr = XTmrCtr_GetControlStatusReg(Timer.BaseAddress, TIMER0);
    XTmrCtr_SetControlStatusReg(Timer.BaseAddress, TIMER0,
        csr | XTC_CSR_INT_OCCURED_MASK);
}

int main(void)
{
    if (init_gpio() != XST_SUCCESS) return XST_FAILURE;
    if (init_timer() != XST_SUCCESS) return XST_FAILURE;

    /* LED0 초기 소등: 기존 AXI GPIO 채널 1 출력 */
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    while (1) {
        timer_value = XTmrCtr_GetValue(&Timer, TIMER0);
        if (XTmrCtr_IsExpired(&Timer, TIMER0)) {
            clear_timer_expired();
            expire_count++;
            led_state ^= LED0_MASK;  /* 0 → 1 → 0 반복 */
            XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);
        }
    }
}
코드의미
XTmrCtr_SetResetValue()49,999,998을 TLR0에 설정
XTmrCtr_Start()Timer 0 시작
XTmrCtr_IsExpired()만료 상태 폴링
clear_timer_expired()T0INT 플래그를 1 쓰기로 제거

FPGA Program · Run/Debug

검증된 07장 UART Echo를 다시 제작하지 않습니다.

  1. Basys3 연결
    USB(JTAG) 연결과 전원을 확인합니다. JP1은 JTAG 모드로 유지합니다.
  2. 08장 비트스트림 다운로드
    Vivado Hardware Manager → Open Target / Auto Connect → Program Device에서 08장 Bitstream 선택. 07장 Bitstream을 다시 사용하지 않습니다.
  3. Vitis Run/Debug 설정
    08장 Application FLOW에서 Debug 설정(launch.json 탭)을 열어 08장 ELF, 플랫폼, 비트스트림 및 microblaze_riscv_0를 확인합니다.
  4. 디버그 시작
    Debug 실행 후 타깃이 인식되는지 확인합니다. 이전에 확인된 환경에서는 중앙 상단 launch.json 탭을 열고 Debug를 실행했을 때 정상 진입했습니다. 이를 만능 해결책으로 단정하지 않습니다.
  5. LED 관측
    Continue로 실행하여 LED0의 ON/OFF 반전을 관측합니다. 07장의 moserial Echo 실습을 반복하지 않습니다.

SECTION 21검증·정리

실제 결과 확인 · LED0·Watch

아래 시간표는 설계상 목표 주기이며, 실제 LED 점멸 및 Watch 결과는 별도로 확인했습니다.

시간(예상)expire_countLED0
0 s0OFF
0.5 s1ON
1.0 s2OFF
1.5 s3ON

Debug Watch에서 expire_count, led_state, timer_value를 확인합니다. timer_value는 실행 중 계속 변화하며 Breakpoint로 CPU를 멈춰도 타이머 자체가 자동 정지하지 않을 수 있습니다. expire_count는 폴링 루프가 수행한 만료 처리 횟수이지 외부 측정기로 계측한 정밀한 시간값이 아닙니다.

검증 상태 08장 Bitstream 및 ELF Build, 실제 Basys3 LED0 반복 점멸, Watch 변화까지 확인했습니다. 0.5초 주기는 설정식 기준 예상값으로 표시합니다.
