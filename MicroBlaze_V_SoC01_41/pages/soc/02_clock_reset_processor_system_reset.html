SECTION 01

Clock과 Reset의 역할

MicroBlaze V, BRAM Controller, AXI Interconnect, Peripheral은 모두 Clock을 기준으로 상태가 변한다. Reset은 이 회로들을 알려진 초기 상태로 만들고, Clock이 안정된 뒤 정해진 순서로 동작을 시작하게 한다.

Basys3 100 MHz → Clocking Wizard → System Clock → Processor System Reset → MicroBlaze V / Bus / Peripheral
① 기준 Clock

FPGA 내부 모든 동기 회로의 시간 기준을 만든다.

② Clock Lock

Clocking Wizard가 안정화되었는지 locked로 알린다.

③ Reset 생성

Processor System Reset이 용도별 Reset을 생성한다.

④ 순차 해제

Bus → Peripheral → CPU 순으로 Reset을 해제한다.

SECTION 02

Basys3 100 MHz Clock

Basys3 Reference Manual은 보드에 단일 100 MHz oscillator가 있고 FPGA의 W5 핀으로 들어간다고 설명한다. W5는 Bank 34의 MRCC(Multi-Region Clock Capable, 여러 Clock 영역으로 전달 가능한 Clock 입력)이다.

항목Basys3 기준SoC 02에서의 역할
Oscillator100 MHzClocking Wizard의 입력 Clock
FPGA PinW5XDC의 Primary Clock 입력
Clock Period10 nsVivado Timing 기준
IOSTANDARDLVCMOS33Basys3 Clock 입력 전기 규격
f = 100 MHz T = 1 / f T = 10 ns

따라서 XDC에서 create_clock의 period는 10.00 ns로 지정한다.

SECTION 03

Clocking Wizard

Clocking Wizard는 FPGA 내부 MMCM/PLL 자원을 이용해 입력 Clock으로부터 필요한 주파수와 위상의 Clock을 만든다. SoC 02에서는 입력과 출력 모두 100 MHz를 사용하더라도, 시스템 Clock 생성과 locked 상태 관리를 위해 Clocking Wizard를 그대로 유지한다.

W5 · 100 MHz → clk_wiz_1 → clk_out1 · 100 MHz → MicroBlaze V / LMB / proc_sys_reset
신호방향의미
clk_in1입력Basys3 100 MHz 기준 Clock
clk_out1출력MicroBlaze V SoC 내부 System Clock
reset입력Clocking Wizard 자체 Reset
locked출력Clock 회로가 안정되어 출력 Clock을 사용할 수 있음을 알리는 상태
locked는 일반적인 동작 완료 신호가 아니라 Clock 생성 회로가 안정된 상태를 의미한다. CPU Reset 해제 판단에 사용한다.
SECTION 04

Processor System Reset

Processor System Reset은 외부 Reset, Debug Reset, Clock lock 상태를 받아 MicroBlaze V·Bus·AXI Peripheral에 필요한 여러 종류의 Reset을 만든다. 하나의 버튼 Reset을 모든 블록에 직접 연결하는 대신 각 회로의 극성과 해제 순서를 맞추는 역할을 담당한다.

방향신호
입력slowest_sync_clk / ext_reset_in / aux_reset_in / mb_debug_sys_rst / dcm_locked
출력mb_reset / bus_struct_reset / peripheral_reset / interconnect_aresetn / peripheral_aresetn

AMD PG164는 이 IP를 Processor/Bus/Peripheral이 한 Clock 체계 안에서 안전하게 Reset되도록 하는 전용 Reset 모듈로 설명한다.

SECTION 06

Active-High · Active-Low

표기Reset이 걸린 상태Reset이 풀린 상태
mb_reset10
bus_struct_reset10
peripheral_reset10
interconnect_aresetn01
peripheral_aresetn01
reset : 1 → RESET aresetn : 0 → RESET suffix "_n" 또는 "aresetn" → 보통 Low일 때 Reset이 활성화됨

AXI 계열 IP는 aresetn이라는 Active-Low Reset을 많이 사용한다. 따라서 peripheral_aresetn을 AXI Peripheral의 s_axi_aresetn 등에 연결할 때 별도의 반전기를 임의로 넣지 않는다.

SECTION 07

locked → dcm_locked

AMD UG1711는 Board Flow를 사용하지 않는 경우에도 Clocking Wizard의 locked 출력을 Processor System Reset의 dcm_locked 입력에 연결해야 한다고 명시한다.

clk_wiz_1/locked → rst_clk_wiz_1_100M/dcm_locked

PG164에 따르면 dcm_locked가 동작 중 Low로 내려가면 Processor System Reset은 모든 Reset 출력을 다시 활성화한다. 따라서 Clock이 불안정한 동안 CPU와 Bus가 동작을 계속하지 않도록 막는다.

필수 확인: locked와 dcm_locked가 끊겨 있으면 CPU가 Reset에서 정상적으로 빠져나오지 못하거나, Clock 안정 상태와 무관하게 Reset이 제어될 수 있다.
SECTION 08

slowest_sync_clk

slowest_sync_clk는 Processor System Reset 내부의 동기화 및 Reset 해제 시퀀스가 기준으로 삼는 Clock이다. PG164는 시스템에서 사용하는 동기 Clock 중 가장 느린 Clock에 연결하도록 설명하며, 일반적으로 AXI4-Lite Clock을 예로 든다.

SoC 02는 하나의 100 MHz Clock Domain만 사용하므로 다음과 같이 연결한다.

clk_wiz_1/clk_out1 · 100 MHz → proc_sys_reset/slowest_sync_clk
나중에 서로 다른 Clock Domain이 추가되면 Reset도 각 Clock Domain에 맞게 다시 설계해야 한다. 하나의 peripheral_aresetn을 모든 비동기 Clock Domain에 무조건 공유하면 안 된다.
SECTION 09

Reset 해제 순서

PG164는 Reset이 활성화될 때는 출력들이 함께 활성화되지만, Reset 해제는 순서를 두어 진행한다고 설명한다.

순서해제되는 Reset100 MHz 기준의미
1bus_struct_reset, interconnect_aresetn기준 시점Bus/Interconnect를 먼저 준비
2peripheral_reset, peripheral_aresetn16 clocks 후 ≈ 160 nsPeripheral 동작 허용
3mb_reset추가 16 clocks 후 ≈ 320 nsCPU가 마지막에 실행 시작
Clock Stable ↓ Bus / Interconnect Reset 해제 ↓ 16 clocks Peripheral Reset 해제 ↓ 16 clocks MicroBlaze V Reset 해제 ↓ CPU 실행 시작

이 160 ns, 320 ns 값은 Reset 해제 시퀀스 구간만 100 MHz로 환산한 값이다. 외부 Reset 입력 검출, Clock lock 획득 시간까지 포함한 전체 Reset 시간은 이 값보다 길 수 있다.

SECTION 13

Basys3 XDC

Digilent Master XDC의 Clock과 Center Button 줄만 활성화하고, Block Design에서 만든 외부 포트 이름과 일치시킨다.

## Clock signal
set_property -dict { PACKAGE_PIN W5 IOSTANDARD LVCMOS33 } [get_ports clk]
create_clock -add -name sys_clk_pin -period 10.00 -waveform {0 5} [get_ports clk]

## Center Button : Reset
set_property -dict { PACKAGE_PIN U18 IOSTANDARD LVCMOS33 } [get_ports btnC]
포트핀기능
clkW5100 MHz Primary Clock
btnCU18Active-High 외부 Reset 입력
외부 포트가 clk_0, reset_0처럼 자동 생성되었다면 XDC를 먼저 바꾸지 말고 Block Design의 외부 포트 이름을 의도한 clk, btnC로 정리한 뒤 XDC와 맞춘다.
SECTION 14

Processor System Reset 설정

Basys3 Center Button은 누르면 High가 되는 입력으로 사용하므로 ext_reset_in도 Active-High로 맞추는 것이 직관적이다.

항목SoC 02 기준이유
External Reset Logic LevelActive-HighBTNC 누름 = High
Auxiliary Reset미사용현재 내부 보조 Reset 없음
MicroBlaze Debug ResetMDM V 연결Debug Reset 경로 유지
dcm_lockedclk_wiz_1/lockedClock 안정 상태 반영
slowest_sync_clk100 MHz System Clock현재 단일 Clock Domain

외부 Push Button은 FPGA Clock과 비동기이며 기계적 바운스가 발생할 수 있다. Processor System Reset은 Reset 입력 검출과 동기화 기능을 제공하지만, 이를 일반적인 Push Button Debouncer로 간주하지 않는다.

MDM V의 Debug_SYS_Rst는 mb_debug_sys_rst로 연결한다. aux_reset_in을 사용하지 않으면 Active-High 설정에서 0으로 고정한다.

SECTION 15

신호 경로 추적

Block Design에서 아래 다섯 경로를 실제 Wire를 따라가며 확인한다.

  1. Primary Clock

    clk → clk_wiz_1/clk_in1

  2. Generated Clock

    clk_wiz_1/clk_out1 → microblaze_riscv_0/Clk

  3. Lock

    clk_wiz_1/locked → proc_sys_reset/dcm_locked

  4. External Reset

    btnC → proc_sys_reset/ext_reset_in

  5. CPU Reset

    proc_sys_reset/mb_reset → microblaze_riscv_0/Reset

이 다섯 경로가 설명과 실제 Block Design에서 일치해야 SoC 02의 핵심 구조가 완성된다.
SECTION 16

Validate Design — 첫 번째 Stage Gate · Timing 확인

  1. 첫 Validate Design

    SoC 02 SECTION 12~15에서 Basys3 외부 Clock/Reset 포트와 내부 필수 경로 연결을 완료하고 Ctrl+S로 저장한 뒤 Validate Design을 실행한다. SoC 01의 미연결 중간 상태에서는 실행하지 않는다.

  2. Clock Association

    MicroBlaze V, Local Memory, Processor System Reset이 동일한 100 MHz Clock에 연결되었는지 확인한다.

  3. Reset Association

    AXI 계층이 아직 최소 구성이라도 interconnect_aresetn, peripheral_aresetn이 올바른 극성으로 생성되는지 확인한다.

  4. Report Clocks

    Synthesis 이후 100 MHz Primary Clock이 10 ns Period로 인식되는지 확인한다.

Gate 1 PASS 기준: Clock 입력 100 MHz, Clock Wizard lock 경로, Processor System Reset 입력/출력, MicroBlaze V Reset 경로가 모두 연결되고 Validate Design이 오류 없이 완료되어야 한다. Messages에서 Clock/Reset과 미연결 Interface 오류를 함께 확인한다. 사용하지 않을 AXI 인터페이스의 미완성 주소 경고도 원인을 확인한다.

SUMMARY

SoC 02 완료 체크리스트

  • [ ] Basys3 100 MHz Clock가 W5로 정의되어 있다.
  • [ ] XDC의 Clock Period가 10.00 ns이다.
  • [ ] Clocking Wizard 입력과 출력 Clock을 구분할 수 있다.
  • [ ] clk_wiz_1/locked → proc_sys_reset/dcm_locked가 연결되어 있다.
  • [ ] clk_wiz_1/clk_out1 → proc_sys_reset/slowest_sync_clk가 연결되어 있다.
  • [ ] btnC(U18) → ext_reset_in이 연결되어 있다.
  • [ ] mb_reset이 Active-High임을 이해한다.
  • [ ] interconnect_aresetn, peripheral_aresetn이 Active-Low임을 이해한다.
  • [ ] Reset 해제 순서가 Bus/Interconnect → Peripheral → MicroBlaze V임을 이해한다.
  • [ ] 100 MHz에서 16 clocks가 약 160 ns임을 계산할 수 있다.
  • [ ] Block Design에서 다섯 핵심 Signal Path를 실제로 추적했다.
  • [ ] SoC 02 SECTION 16에서 첫 Validate Design이 오류 없이 성공하여 Gate 1 PASS를 확인했다.
