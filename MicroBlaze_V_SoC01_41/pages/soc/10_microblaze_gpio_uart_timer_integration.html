SECTION 01실습 목표

GPIO · UART · Timer 통합 실습 목표

Basys3의 스위치 14개는 LED0~LED13에 표시하고, UART 명령으로 LED14를 제어하며, Timer 인터럽트로 LED15를 깜빡이게 합니다. 앞 장에서 구현한 세 주변장치 기능을 하나의 MicroBlaze V C 프로그램에서 동시에 실행합니다.

SW[13:0] → AXI GPIO Channel 2 → MicroBlaze V → AXI GPIO Channel 1 → LED[13:0]
Ubuntu UART 문자 '1'/'0' → AXI UART Lite → MicroBlaze V → AXI GPIO → LED14
AXI Timer → AXI INTC → MicroBlaze V → Main Loop → AXI GPIO → LED15
입력·동작예상 출력
SW0 ONLED0 ON
SW3 ONLED3 ON
UART 문자 1 / 0LED14 ON / OFF
Timer 인터럽트 약 0.5초 간격LED15 ON / OFF 반복
UART 문자 r / h상태 / 도움말을 터미널에 출력

10장은 09장의 정상 하드웨어를 별도 프로젝트로 복제하고 Local BRAM을 16 KiB에서 64 KiB로 확장합니다. GPIO·UART Lite·Timer·INTC 연결은 유지한 채 10장 Bitstream·XSA·Platform을 새로 생성합니다. Vitis에서는 이미 작성한 soc10_integration 프로그램을 새 Platform에 연결하여 통합 동작을 확인합니다. 기존 09장 프로젝트는 보존합니다.

SECTION 02통합 구성

09장 성공 프로젝트 복제 · BRAM 64 KiB 확장

09장 AXI INTC 실기 성공 프로젝트를 /home/jung/soc/hw/soc10_integration으로 복제합니다. CPU·AXI 주변장치·Clock·Reset·인터럽트 연결은 유지하고 Local BRAM 용량만 64 KiB로 확장합니다.

microblaze_riscv_0/M_AXI_DP → axi_smc → axi_gpio_0 / axi_uartlite_0 / axi_timer_0 / axi_intc_0
axi_timer_0/interrupt → axi_intc_0/intr[0:0] → axi_intc_0/interrupt → microblaze_riscv_0/INTERRUPT
항목09장 성공 구성10장 확장 목표
Local BRAM16 KiB64 KiB · 기존의 4배
ILMB / DLMB 주소0x00000000~0x00003FFF0x00000000~0x0000FFFF
AXI GPIO · UART Lite · Timer · INTC기존 주소·배선모두 유지
Vivado XPRsoc09_axi_interrupt.xprsoc10_integration.xpr
Vitis Platformsoc09_axi_interrupt_platformsoc10_integration_platform 신규

Basys3 Artix-7에는 총 1,800 Kbits의 Block RAM이 있습니다. 64 KiB의 데이터 용량은 512 Kibits로 전체 물리 BRAM의 약 28%에 해당합니다. 128 KiB는 약 57%이므로 이후 사용자 RTL·FIFO·NPU 버퍼 자원을 고려하여 64 KiB를 교육용 확장 기준으로 선택합니다. 실제 BRAM 점유 개수와 Timing은 Vivado 구현 결과로 확인합니다.

Timer는 인터럽트, UART는 Polling(폴링, 상태 반복 확인) 방식 그대로입니다. 64 KiB는 10장 코드의 성공 결과가 아니라 새 하드웨어의 설계 목표입니다.

SECTION 04통합 구성

UART·Timer 실행 방식 구분

UART의 수신 FIFO는 Main Loop에서 비차단 확인하며 Timer는 인터럽트 Callback으로 처리합니다.

XUartLite_IsReceiveEmpty()로 수신 여부를 확인한 뒤 문자가 있을 때만 읽습니다. Timer Callback에서는 interrupt_count++만 실행합니다.

SECTION 05통합 구성

LED 출력 충돌 방지

GPIO Channel 1에 쓰는 최종 값은 Main Loop가 단 한 곳에서 합성합니다.

new_led_state =
    (switch_value & SW_LED_MASK) |
    uart_led_state |
    heartbeat_state;

SW14·SW15는 이 예제에서 LED14·LED15의 직접 복사 대상에서 제외됩니다.

SECTION 09Vivado · Local BRAM 확장

Address Editor에서 ILMB · DLMB를 64K로 확장

공유 Local BRAM이므로 Instruction과 Data 두 주소 경로가 같은 64 KiB 물리 RAM을 바라보아야 합니다.

  1. Instruction · ILMB
    10장 복제 BD의 Address Editor에서 해당 Local BRAM 경로의 Range를 64K로 조정하고 Base 0x00000000을 유지합니다.
  2. Data · DLMB
    같은 Local BRAM의 Data 경로도 Range를 64K로 조정합니다. 예상 High Address는 두 경로 모두 0x0000FFFF입니다.
  3. 실제 RAM 용량 동기화
    Address Editor 변경 후 Local Memory의 Block Memory Generator 용량과 두 LMB Controller 주소 범위가 함께 바뀌었는지 확인합니다. 자동 반영되지 않으면 실제 Vivado GUI 설정을 확인하여 수동 조정합니다. 주소 범위 표시만 64K로 바꾸고 물리 RAM이 16 KiB로 남으면 안 됩니다.
확인 항목목표값
Local BRAM Base0x00000000
Instruction / Data Range64K · 두 경로 동일
High Address0x0000FFFF
물리 Block Memory Generator 깊이64 KiB 용량에 해당하는 실제 설정

64 KiB 변경이 실제 하드웨어에 적용되었는지 검증합니다.

    Tools → Validate Design을 실행하고 오류와 Critical Warning을 확인합니다.

SECTION 16Vitis 통합 실습

새 xparameters.h · lscript.ld 64 KiB 검증

09장 BSP의 GPIO·UART·Timer·INTC 주소는 유지하면서, 새 10장 Platform의 Local BRAM 용량을 Linker Script(링커 스크립트, 메모리 배치 설정)까지 반영합니다.

  1. 새 BSP xparameters.h
    GPIO 0x40000000, UART Lite 0x40600000, INTC 0x41200000, Timer 0x41C00000을 확인합니다.
  2. Linker Script 메모리 크기
    soc10_integration/src/lscript.ld에서 lmb_bram_0 주소가 ORIGIN = 0x00000000, LENGTH = 0x10000(64 KiB)에 해당하는지 확인합니다. 09장 Platform 기반으로 자동 생성한 기존 0x4000(16 KiB) 길이가 남아 있다면 새 Platform을 기준으로 재생성하거나 해당 메모리 영역을 갱신합니다.
  3. Heap/Stack
    64 KiB 확장 후에는 Heap·Stack을 임의로 줄이지 않고 기본 예약값을 유지합니다. 이전 Build의 lmb_bram_0 overflowed by 64 bytes 오류가 해결되는지 새 Platform으로 Build하여 확인합니다.

    입력·인터럽트에 따라 변수와 최종 LED 출력이 올바르게 변하는지 확인합니다.
SECTION 25Vitis 통합 실습

동시 동작 최종 검증

GPIO + UART + Timer/INTC 네 기능이 하나의 Application에서 동시에 정상 동작하면 10장 완료입니다.

  1. 동시 조작
    UART 명령을 반복해서 보내면서 SW를 조작하고 LED15의 점멸이 계속되는지 확인합니다.
  2. 증거 정리
    성공 화면만 순서대로 기록하고 오류·미검증 화면은 최종 성공 사례에서 제외합니다.
SECTION 26Vitis 코드

통합 main.c — 전체 코드

다음은 10장 통합 실습용 C 코드입니다. 각 함수의 쉬운 풀이와 CPU·메모리 동작은 10.1장에서 설명합니다.

main.c
#include "xparameters.h"
#include "xgpio.h"
#include "xuartlite_l.h"
#include "xtmrctr.h"
#include "xstatus.h"
#include "xil_types.h"
#include "xil_exception.h"

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif

/*
 * SoC 10 - MicroBlaze V + GPIO + UART + Timer + AXI INTC Integration
 *
 * GPIO Channel 1 : LED[15:0] output
 * GPIO Channel 2 : SW[15:0] input
 *
 * LED ownership:
 *   LED[13:0] : SW[13:0] mirror
 *   LED14     : UART command control ('1' = ON, '0' = OFF)
 *   LED15     : Timer interrupt heartbeat
 *
 * UART : Polling, 115200 8N1
 * Timer: 100 MHz, 0.5 s interval, Down Count + Auto Reload + Interrupt
 * IRQ  : AXI Timer -> AXI INTC -> MicroBlaze V
 */

#define GPIO_LED_CHANNEL        1U
#define GPIO_SW_CHANNEL         2U

#define SW_LED_MASK             0x00003FFFU
#define UART_LED_MASK           0x00004000U
#define HEARTBEAT_LED_MASK      0x00008000U

#define TIMER0                  0U
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

#ifndef SDT
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#define UART_BASEADDR           XPAR_UARTLITE_0_BASEADDR
#else
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define UART_BASEADDR           XPAR_XUARTLITE_0_BASEADDR
#endif

static XGpio Gpio;
static XTmrCtr Timer;

#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U;
volatile u32 switch_value    = 0U;
volatile u32 led_state       = 0U;
volatile u8  last_uart_rx    = 0U;

static u32 uart_led_state = 0U;

static void UartPutChar(u8 ch)
{
    XUartLite_SendByte(UART_BASEADDR, ch);
}

static void UartPutString(const char *text)
{
    while (*text != '\0') {
        UartPutChar((u8)*text);
        text++;
    }
}

static void UartPutHexNibble(u8 value)
{
    value &= 0x0FU;

    if (value < 10U) {
        UartPutChar((u8)('0' + value));
    } else {
        UartPutChar((u8)('A' + (value - 10U)));
    }
}

static void UartPutHex16(u16 value)
{
    int shift;

    for (shift = 12; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void UartPutHex32(u32 value)
{
    int shift;

    for (shift = 28; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void PrintHelp(void)
{
    UartPutString("\r\nCommands\r\n");
    UartPutString("  1 : LED14 ON\r\n");
    UartPutString("  0 : LED14 OFF\r\n");
    UartPutString("  r : Read status\r\n");
    UartPutString("  h : Help\r\n");
}

static void PrintStatus(void)
{
    UartPutString("\r\nSW=0x");
    UartPutHex16((u16)switch_value);
    UartPutString(" LED=0x");
    UartPutHex16((u16)led_state);
    UartPutString(" IRQ=0x");
    UartPutHex32(interrupt_count);
    UartPutString("\r\n");
}

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}

static void InitUart(void)
{
    /* RX/TX FIFO clear. UART interrupt remains disabled. */
    XUartLite_WriteReg(
        UART_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );
}

static void HandleUartCommand(void)
{
    if (XUartLite_IsReceiveEmpty(UART_BASEADDR)) {
        return;
    }

    last_uart_rx = XUartLite_RecvByte(UART_BASEADDR);

    switch (last_uart_rx) {
    case '1':
        uart_led_state = UART_LED_MASK;
        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;
    }
}

static void UpdateLedOutput(void)
{
    u32 new_led_state;
    u32 heartbeat_state;

    if ((interrupt_count & 1U) != 0U) {
        heartbeat_state = HEARTBEAT_LED_MASK;
    } else {
        heartbeat_state = 0U;
    }

    new_led_state =
        (switch_value & SW_LED_MASK) |
        uart_led_state |
        heartbeat_state;

    if (new_led_state != led_state) {
        led_state = new_led_state;
        XGpio_DiscreteWrite(
            &Gpio,
            GPIO_LED_CHANNEL,
            led_state
        );
    }
}

int main(void)
{
    int status;

    status = InitGpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    InitUart();

    status = InitTimer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = SetupInterruptSystem();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    led_state = 0U;
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    UartPutString("\r\nSoC 10 Integrated System Ready\r\n");
    PrintHelp();

    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        switch_value = XGpio_DiscreteRead(
            &Gpio,
            GPIO_SW_CHANNEL
        );

        HandleUartCommand();
        UpdateLedOutput();
    }

    return XST_SUCCESS;
}
