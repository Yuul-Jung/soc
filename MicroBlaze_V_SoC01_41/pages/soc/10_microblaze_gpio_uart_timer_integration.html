SECTION 01실습 목표

GPIO · UART · Timer 통합 실습 목표

Basys3의 스위치 14개는 LED0~LED13에 표시하고, UART 명령으로 LED14를 제어하며, Timer 인터럽트로 LED15를 깜빡이게 합니다. 앞 장에서 구현한 세 주변장치 기능을 하나의 MicroBlaze V C 프로그램에서 동시에 실행합니다.

SW[13:0] → AXI GPIO Channel 2 → MicroBlaze V → AXI GPIO Channel 1 → LED[13:0]
Ubuntu UART 문자 '1'/'0' → AXI UART Lite → MicroBlaze V → AXI GPIO → LED14
AXI Timer → AXI INTC → MicroBlaze V → Main Loop → AXI GPIO → LED15
입력·동작예상 출력
SW0 ONLED0 ON
SW3 ONLED3 ON
UART 문자 1 / 0LED14 ON / OFF
Timer 인터럽트 약 0.5초 간격LED15 ON / OFF 반복
UART 문자 r / h상태 / 도움말을 터미널에 출력

10장은 09장의 정상 하드웨어를 별도 프로젝트로 복제하고 Local BRAM을 16 KiB에서 64 KiB로 확장합니다. GPIO·UART Lite·Timer·INTC 연결은 유지한 채 10장 Bitstream·XSA·Platform을 새로 생성합니다. Vitis에서는 이미 작성한 soc10_integration 프로그램을 새 Platform에 연결하여 통합 동작을 확인합니다. 기존 09장 프로젝트는 보존합니다.

SECTION 02통합 구성

09장 성공 프로젝트 복제 · BRAM 64 KiB 확장

09장 AXI INTC 실기 성공 프로젝트를 ~/soc/hw/soc10_integration으로 복제합니다. CPU·AXI 주변장치·Clock·Reset·인터럽트 연결은 유지하고 Local BRAM 용량만 64 KiB로 확장합니다.

microblaze_riscv_0/M_AXI_DP → axi_smc → axi_gpio_0 / axi_uartlite_0 / axi_timer_0 / axi_intc_0
axi_timer_0/interrupt → axi_intc_0/intr[0:0] → axi_intc_0/interrupt → microblaze_riscv_0/INTERRUPT
항목09장 성공 구성10장 확장 목표
Local BRAM16 KiB64 KiB · 기존의 4배
ILMB / DLMB 주소0x00000000~0x00003FFF0x00000000~0x0000FFFF
AXI GPIO · UART Lite · Timer · INTC기존 주소·배선모두 유지
Vivado XPRsoc09_axi_interrupt.xprsoc10_integration.xpr
Vitis Platformsoc09_axi_interrupt_platformsoc10_integration_platform 신규

Basys3 Artix-7에는 총 1,800 Kbits의 Block RAM이 있습니다. 64 KiB의 데이터 용량은 512 Kibits로 전체 물리 BRAM의 약 28%에 해당합니다. 128 KiB는 약 57%이므로 이후 사용자 RTL·FIFO·NPU 버퍼 자원을 고려하여 64 KiB를 교육용 확장 기준으로 선택합니다. 실제 BRAM 점유 개수와 Timing은 Vivado 구현 결과로 확인합니다.

Timer는 인터럽트, UART는 Polling(폴링, 상태 반복 확인) 방식 그대로입니다. 64 KiB는 10장 코드의 성공 결과가 아니라 새 하드웨어의 설계 목표입니다.

SECTION 04통합 구성

UART·Timer 실행 방식 구분

UART의 수신 FIFO는 Main Loop에서 비차단 확인하며 Timer는 인터럽트 Callback으로 처리합니다.

XUartLite_IsReceiveEmpty()로 수신 여부를 확인한 뒤 문자가 있을 때만 읽습니다. Timer Callback에서는 interrupt_count++만 실행합니다.

SECTION 05통합 구성

LED 출력 충돌 방지

GPIO Channel 1에 쓰는 최종 값은 Main Loop가 단 한 곳에서 합성합니다.

new_led_state =
    (switch_value & SW_LED_MASK) |
    uart_led_state |
    heartbeat_state;

SW14·SW15는 이 예제에서 LED14·LED15의 직접 복사 대상에서 제외됩니다.

SECTION 08Vivado · Local BRAM

Address Editor · 기존 주소 확인

실제 주소를 먼저 확인한 다음 새 프로젝트에서 Local BRAM만 확장합니다.

  1. Address Editor 열기
    soc10_integration Diagram 위의 Address Editor 탭을 누릅니다.
  2. Data와 Instruction 확인
    Network 0의 dlmb_bram_if_cntlr/SLMB와 Network 1의 ilmb_bram_if_cntlr/SLMB를 펼칩니다. 두 행의 초기 Base는 0x0000_0000, Range는 16K, High는 0x0000_3FFF입니다.
  3. AXI와 구분
    GPIO 0x4000_0000, UART Lite 0x4060_0000, INTC 0x4120_0000, Timer 0x41C0_0000의 64K는 각 주변장치의 주소 할당 범위이므로 변경하지 않습니다.
주소 표기: BRAM의 0x0000_4000과 GPIO의 0x4000_0000은 서로 다른 값입니다. 주소는 16진수 네 자리씩 구분해서 읽습니다. 초기 Address Editor 화면은 Assigned (6), Unassigned (0)으로 확인됐습니다.
SECTION 09Vivado · Local BRAM

ILMB · DLMB를 16K → 64K로 변경

Instruction(명령)과 Data(데이터)는 하나의 공유 Local BRAM에 접근합니다. 두 주소 경로 모두 같은 범위로 변경합니다.

  1. ILMB Range 변경
    Network 1 → microblaze_riscv_0/Instruction → ilmb_bram_if_cntlr/SLMB 행에서 Range 16K → 64K를 선택한 후 Enter를 누릅니다. High Address가 0x0000_FFFF로 변경되는지 확인합니다.
  2. DLMB Range 변경
    Network 0 → microblaze_riscv_0/Data → dlmb_bram_if_cntlr/SLMB 행에서 Range 16K → 64K를 선택하고 Enter로 확정합니다.
  3. 양쪽 범위 대조
    두 행 모두 Base 0x0000_0000, Range 64K, High 0x0000_FFFF로 표시되는지 확인합니다. AXI GPIO·UART Lite·Timer·INTC 주소는 이전 그대로입니다.
  4. 저장
    Ctrl+S로 Block Design을 저장합니다.
변경 완료 주소BaseRangeHigh
ILMB · Instruction0x0000_000064K0x0000_FFFF
DLMB · Data0x0000_000064K0x0000_FFFF
중간 캡처에는 ILMB만 64K, DLMB는 16K인 화면도 있습니다. 최종 설정값은 두 경로 모두 64K인 이후 화면을 기준으로 합니다.
SECTION 10Vivado · 연결 유지

Local BRAM 내부 · AXI · Clock · Reset 확인

새 10장 Block Design의 실제 화면에서 기존 하드웨어 구성이 유지됨을 확인했습니다.

  1. Local Memory 내부 펼치기
    Diagram으로 돌아와 microblaze_riscv_0_local_memory 왼쪽의 +를 눌러 내부를 펼칩니다.
  2. 공유 RAM 연결 확인
    dlmb_bram_if_cntlr/BRAM_PORT → lmb_bram/BRAM_PORTA, ilmb_bram_if_cntlr/BRAM_PORT → lmb_bram/BRAM_PORTB를 확인합니다. 물리적으로 하나의 True Dual Port RAM입니다.
  3. Block Memory Generator 확인
    lmb_bram을 더블클릭해 Basic 탭의 Mode BRAM Controller, Memory Type True Dual Port RAM, ECC No ECC, 자동 주소 설정을 확인합니다. 값을 수동으로 변경할 필요는 없습니다.
  4. AXI · Interrupt · 외부 포트 확인
    CPU M_AXI_DP → axi_smc → GPIO·UART Lite·Timer·INTC 연결, axi_timer_0/interrupt → axi_intc_0/intr[0:0] → axi_intc_0/interrupt → CPU INTERRUPT, 외부 led·sw·UART_0가 유지되는지 확인합니다.

10장 통합 구성도 열기 — 이 SVG는 신호 관계를 설명하는 구조도이며, Vivado GUI 원본 캡처는 아닙니다.

SECTION 11Vivado · 설계 검증

Validate Design · BRAM IP Summary

이 SECTION은 설계 연결과 64K 메모리 설정의 일관성만 확인합니다. 구현 자원·최종 타이밍 보고서는 SECTION 12에서 확인합니다.

  1. Validate Design
    Diagram 툴바의 Validate Design 버튼을 누르거나 Tools → Validate Design을 실행합니다.
  2. 검증 결과 확인
    실제 화면에 Validation successful! There are no errors or critical warnings in this design.가 표시됐습니다. OK를 누릅니다.
  3. BRAM Summary 확인
    lmb_bram을 더블클릭 → Summary 탭을 선택합니다. 실제 표시된 값은 36K BRAM 16개, 18K BRAM 0개, Port A/B Read Latency 각 1 Clock, Address Width A/B 각 32입니다.
  4. 설정 창 닫고 저장
    설정을 변경하지 않았으므로 Cancel을 누른 후 Ctrl+S로 저장합니다.

SECTION 12Vivado · 구현 검증

Generate Bitstream → Utilization · Timing

합성과 구현이 끝난 뒤에만 구현 자원과 최종 Timing을 판정합니다. 불필요한 Generate Output Products 수동 실행은 포함하지 않습니다.

  1. 프로젝트 저장 · Top 확인
    Ctrl+S로 저장하고 Sources의 Top이 soc10_integration_wrapper인지 확인합니다.
  2. Generate Bitstream
    왼쪽 Flow Navigator → PROGRAM AND DEBUG → Generate Bitstream을 클릭합니다. Synthesis 또는 Implementation 미완료 안내가 나오면 필요한 실행을 승인합니다. Project Mode에서는 필요한 Output Products를 빌드 과정에서 자동으로 생성합니다.
  3. 실행 결과 확인
    Synthesis → Implementation → Bitstream 생성이 모두 성공했는지 확인합니다. 실패하면 첫 번째 오류 메시지를 확인한 뒤 진행을 중단합니다.
  4. Open Implemented Design
    Bitstream 생성 완료 후 Open Implemented Design을 엽니다.
  5. Report Utilization
    Reports → Report Utilization에서 Block RAM Tile과 RAMB36E1 사용량, LUT, FF를 확인합니다. IP Summary의 BRAM36 16개와 실제 구현 자원 수는 구별합니다.
  6. Report Timing Summary
    Reports → Report Timing Summary에서 Setup WNS/TNS, Hold WHS/THS, Pulse Width, Clock Summary와 Check Timing / Unconstrained Paths를 확인합니다. WNS 하나만으로 전체 타이밍이 통과됐다고 판정하지 않습니다.

SECTION 13Vivado · 하드웨어 내보내기

SECTION 14Vitis 통합 실습

10장 XSA로 Vitis Platform 생성

새 XSA의 64 KiB Local BRAM 정보가 포함된 soc10_integration_platform을 생성합니다. 기존 09장 Platform은 그대로 보존합니다.

SECTION 15Vitis 통합 실습

새 Application 생성 · 10장 Platform 선택

10장 전용 soc10_integration_platform에서 새로운 Application(애플리케이션, 실행 프로그램)을 생성합니다. 기존 09장 Platform을 선택하지 않습니다.

  1. 새 Application 마법사 열기
    Vitis Unified IDE 2024.2에서 File → New Component → Application을 선택하고 Empty Application(빈 애플리케이션) 생성 화면을 엽니다.
  2. Name and Location(이름과 경로)
    Component name은 soc10_integration, Component location은 ~/soc/sw를 기준으로 지정합니다. 생성 폴더가 ~/soc/sw/soc10_integration인지 확인하고 Next를 누릅니다.
  3. Hardware(하드웨어 Platform)
    Platform 목록에서 반드시 soc10_integration_platform을 선택합니다. 이름이 비슷한 soc09_axi_interrupt_platform을 선택하면 16 KiB 설정을 다시 사용하게 됩니다. Next를 누릅니다.
  4. Domain(도메인)
    OS standalone, Processor microblaze_riscv_0에 해당하는 standalone_microblaze_riscv_0 도메인을 선택하고 Next를 누릅니다.
  5. Source Files(소스 파일)
    빈 Application을 사용합니다. 기본 템플릿을 추가하지 않고 Next로 진행합니다.
  6. Summary(최종 확인) · Finish
    Name soc10_integration, Platform soc10_integration_platform, Domain standalone_microblaze_riscv_0가 일치하는지 확인하고 Finish를 누릅니다.
  7. Vitis Explorer 확인
    Explorer에 soc10_integration [Application]이 생성됐는지 확인합니다. Sources → src에서 lscript.ld를 확인하고 다음 SECTION으로 이동합니다.
프로젝트 경로: ~/soc/는 Ubuntu 사용자의 홈 디렉터리를 기준으로 한 예시입니다. GUI의 폴더 선택 창에서는 각자 설치한 작업 디렉터리를 선택합니다.
SECTION 16Vitis 통합 실습

Platform의 xparameters.h · Application의 lscript.ld 확인

두 파일은 위치와 역할이 다릅니다. xparameters.h는 Platform(하드웨어 정보·BSP)에서, lscript.ld는 Application(링커의 메모리 배치)에서 확인합니다.

  1. ① Platform에서 xparameters.h 열기
    Vitis Explorer → soc10_integration_platform [Platform] → microblaze_riscv_0 → standalone_microblaze_riscv_0 → bsp → include → xparameters.h를 엽니다.
  2. ② 주변장치 주소 확인
    XPAR_AXI_GPIO_0_BASEADDR의 0x4000_0000, AXI INTC의 0x4120_0000, UART Lite의 0x4060_0000, Timer의 0x41C0_0000를 확인합니다. 기존 AXI 주변장치 주소는 바꾸지 않습니다.
  3. ③ Application에서 lscript.ld 열기
    Vitis Explorer의 soc10_integration [Application]을 펼쳐 Sources → src → lscript.ld를 더블클릭합니다. Platform 아래에서 찾는 파일이 아닙니다.
  4. ④ Local BRAM 크기 확인
    lscript.ld의 MEMORY 블록에서 lmb_bram_0의 시작 주소가 0x0000_0000, 길이가 0x0001_0000(64 KiB)인지 확인합니다. 표기는 LENGTH = 0x10000처럼 나타날 수 있습니다.
  5. ⑤ 값이 16 KiB로 남아 있을 때
    LENGTH = 0x4000이라면 Application의 Platform 선택 및 Linker Script 생성 기준부터 확인합니다. 다른 Platform을 잘못 선택한 상태에서 숫자만 바꾸지 않습니다.
  6. ⑥ Stack·Heap 설정 확인
    Linker Script의 Stack(스택, 함수 호출 메모리)·Heap(힙, 동적 할당 메모리) 예약 크기를 확인합니다. 64 KiB 구성에서는 먼저 기본 설정을 유지하고 다음 SECTION에서 실제 Build 결과로 판단합니다.

SECTION 26Vitis 코드

통합 main.c — 전체 코드

다음은 10장 통합 실습용 C 코드입니다. 각 함수의 쉬운 풀이와 CPU·메모리 동작은 10.1장에서 설명합니다.

main.c
#include "xparameters.h"
#include "xgpio.h"
#include "xuartlite_l.h"
#include "xtmrctr.h"
#include "xstatus.h"
#include "xil_types.h"
#include "xil_exception.h"

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif

/*
 * SoC 10 - MicroBlaze V + GPIO + UART + Timer + AXI INTC Integration
 *
 * GPIO Channel 1 : LED[15:0] output
 * GPIO Channel 2 : SW[15:0] input
 *
 * LED ownership:
 *   LED[13:0] : SW[13:0] mirror
 *   LED14     : UART command control ('1' = ON, '0' = OFF)
 *   LED15     : Timer interrupt heartbeat
 *
 * UART : Polling, 115200 8N1
 * Timer: 100 MHz, 0.5 s interval, Down Count + Auto Reload + Interrupt
 * IRQ  : AXI Timer -> AXI INTC -> MicroBlaze V
 */

#define GPIO_LED_CHANNEL        1U
#define GPIO_SW_CHANNEL         2U

#define SW_LED_MASK             0x00003FFFU
#define UART_LED_MASK           0x00004000U
#define HEARTBEAT_LED_MASK      0x00008000U

#define TIMER0                  0U
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

#ifndef SDT
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#define UART_BASEADDR           XPAR_UARTLITE_0_BASEADDR
#else
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define UART_BASEADDR           XPAR_XUARTLITE_0_BASEADDR
#endif

static XGpio Gpio;
static XTmrCtr Timer;

#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U;
volatile u32 switch_value    = 0U;
volatile u32 led_state       = 0U;
volatile u8  last_uart_rx    = 0U;

static u32 uart_led_state = 0U;

static void UartPutChar(u8 ch)
{
    XUartLite_SendByte(UART_BASEADDR, ch);
}

static void UartPutString(const char *text)
{
    while (*text != '\0') {
        UartPutChar((u8)*text);
        text++;
    }
}

static void UartPutHexNibble(u8 value)
{
    value &= 0x0FU;

    if (value < 10U) {
        UartPutChar((u8)('0' + value));
    } else {
        UartPutChar((u8)('A' + (value - 10U)));
    }
}

static void UartPutHex16(u16 value)
{
    int shift;

    for (shift = 12; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void UartPutHex32(u32 value)
{
    int shift;

    for (shift = 28; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void PrintHelp(void)
{
    UartPutString("\r\nCommands\r\n");
    UartPutString("  1 : LED14 ON\r\n");
    UartPutString("  0 : LED14 OFF\r\n");
    UartPutString("  r : Read status\r\n");
    UartPutString("  h : Help\r\n");
}

static void PrintStatus(void)
{
    UartPutString("\r\nSW=0x");
    UartPutHex16((u16)switch_value);
    UartPutString(" LED=0x");
    UartPutHex16((u16)led_state);
    UartPutString(" IRQ=0x");
    UartPutHex32(interrupt_count);
    UartPutString("\r\n");
}

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}

static void InitUart(void)
{
    /* RX/TX FIFO clear. UART interrupt remains disabled. */
    XUartLite_WriteReg(
        UART_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );
}

static void HandleUartCommand(void)
{
    if (XUartLite_IsReceiveEmpty(UART_BASEADDR)) {
        return;
    }

    last_uart_rx = XUartLite_RecvByte(UART_BASEADDR);

    switch (last_uart_rx) {
    case '1':
        uart_led_state = UART_LED_MASK;
        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;
    }
}

static void UpdateLedOutput(void)
{
    u32 new_led_state;
    u32 heartbeat_state;

    if ((interrupt_count & 1U) != 0U) {
        heartbeat_state = HEARTBEAT_LED_MASK;
    } else {
        heartbeat_state = 0U;
    }

    new_led_state =
        (switch_value & SW_LED_MASK) |
        uart_led_state |
        heartbeat_state;

    if (new_led_state != led_state) {
        led_state = new_led_state;
        XGpio_DiscreteWrite(
            &Gpio,
            GPIO_LED_CHANNEL,
            led_state
        );
    }
}

int main(void)
{
    int status;

    status = InitGpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    InitUart();

    status = InitTimer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = SetupInterruptSystem();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    led_state = 0U;
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    UartPutString("\r\nSoC 10 Integrated System Ready\r\n");
    PrintHelp();

    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        switch_value = XGpio_DiscreteRead(
            &Gpio,
            GPIO_SW_CHANNEL
        );

        HandleUartCommand();
        UpdateLedOutput();
    }

    return XST_SUCCESS;
}
