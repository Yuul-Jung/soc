SECTION 04

Timer Interrupt 특성

Timer interrupt 조건이 발생하고 ENIT0가 활성화되어 있으면 interrupt 출력이 High가 된다. T0INT는 1을 써서 Clear할 때까지 유지된다.

Counter Rollover → T0INT=1 → interrupt=High → ISR 처리 → Clear

SECTION 06

09장 작업본 · AXI Interrupt Controller 추가

  1. 08장 성공 프로젝트 복제

    Vivado에서 08장 Timer 성공 프로젝트를 열고 File → Project → Save As로 09장용 새 작업본을 만듭니다. 예시 이름은 soc09_axi_intc입니다. 실제 저장 경로를 확인합니다.

    주의: 08장 원본 프로젝트와 XSA/ELF는 덮어쓰지 않습니다.
  2. 09장 Block Design 분리

    새 프로젝트에서 Sources → Design Sources의 BD를 확인합니다. 필요하면 File → Save Block Design As로 독립 저장하고 실제 참조 경로를 확인합니다.

  3. AXI INTC 추가

    Block Design Diagram에서 +(Add IP) → AXI Interrupt Controller를 검색해 추가합니다.

    기대 화면: axi_intc_0 블록이 생성됩니다.
  4. 일반 인터럽트 설정

    axi_intc_0 더블클릭 → Fast Interrupt는 사용하지 않고, 입력 인터럽트는 Timer 하나만 사용할 구성으로 설정합니다. 실제 IP 설정창에 보이는 입력 수·유형을 확인하고 저장합니다.

    주의: 다른 장치의 인터럽트나 Fast Interrupt 연결은 09장에 추가하지 않습니다.
SECTION 07

Timer → AXI INTC 인터럽트 연결

  1. Timer interrupt 핀 찾기

    axi_timer_0에서 인터럽트 출력 핀 interrupt를 확인합니다. 08장에서는 사용하지 않았지만 09장에서는 연결합니다.

  2. INTC 입력에 연결

    axi_timer_0/interrupt에서 axi_intc_0/intr의 첫 번째 입력 비트로 드래그하여 연결합니다. 버스 폭이 맞지 않으면 Vivado가 요구하는 폭 구성 또는 Concat 설정을 확인합니다.

    기대 화면: Timer 출력에서 INTC 입력 비트 0까지 하나의 인터럽트 경로가 연결됩니다.
  3. Interrupt Type 확인

    AXI INTC 설정의 Timer 입력에 대한 인터럽트 유형을 Timer 출력 특성과 맞춥니다. 별도 자료의 설정을 무조건 복사하지 말고 PG079/PG099의 IP 정보와 실제 GUI를 대조합니다.

참고: AMD PG079 · Timer Interrupts, AMD PG099 · AXI INTC.

SECTION 08

INTC → MicroBlaze V 연결

  1. MicroBlaze V 인터럽트 포트 확인

    microblaze_riscv_0의 Interrupt 입력이 활성화되어 있는지 Diagram에서 확인합니다. 인터페이스가 없으면 CPU의 Re-customize IP에서 인터럽트 지원 설정을 확인합니다.

  2. INTC 출력 → CPU 입력 연결

    AXI INTC 인터럽트 출력(AMD PG099에서는 irq)을 MicroBlaze V의 INTERRUPT 입력으로 연결합니다. 실제 Vivado 2024.2 화면에서 표시되는 포트명과 방향을 확인한 뒤 배선합니다.

    기대 화면: AXI INTC 출력과 CPU 인터럽트 입력 사이에 한 개의 연결이 생깁니다.
  3. Fast Interrupt 미사용 확인

    CPU·INTC 양쪽에서 일반 외부 인터럽트 경로를 사용하고 Fast Interrupt를 선택하지 않았는지 확인합니다. CPU의 외부 인터럽트 허용은 이후 Vitis 소프트웨어에서도 설정해야 합니다.

문서나 버전에 따라 인터럽트 신호 표기가 irq, interrupt, INTERRUPT로 달라질 수 있습니다. 이름만 같게 만드는 것이 아니라 INTC 출력 → MicroBlaze V 입력 방향을 확인합니다. UG1629 (2024.2) 외부 인터럽트.

SECTION 09

INTC AXI · Clock · Reset 연결

  1. S_AXI 연결 자동화

    Run Connection Automation을 열고 axi_intc_0/S_AXI만 선택해 기존 CPU M_AXI_DP → axi_smc 주소 버스에 연결합니다. Timer의 인터럽트 신호와 AXI 데이터 버스를 혼동하지 않습니다.

  2. 클록·리셋 확인

    axi_intc_0/s_axi_aclk를 기존 AXI Clock에, axi_intc_0/s_axi_aresetn을 Peripheral Reset에 연결합니다.

    기대 화면: GPIO·UART·Timer·INTC의 AXI 주소 경로가 모두 유지됩니다.
  3. 연결 검증

    Diagram에서 Timer→INTC→CPU 인터럽트 경로와 CPU→SmartConnect→INTC AXI 경로가 각각 별도로 존재하는지 확인합니다.

SECTION 19

Interrupt 프로그램

다음 코드는 AMD의 현재 XIntc/XTmrCtr/SDT Interrupt 흐름을 기준으로 작성한 교육용 예제이다.

#include "xparameters.h"
#include "xtmrctr.h"
#include "xgpio.h"
#include "xstatus.h"
#include "xil_types.h"
#include "xil_exception.h"

#ifdef SDT
#include "xinterrupt_wrap.h"
#else
#include "xintc.h"
#endif

/*
 * SoC 09 - AXI Interrupt Controller + AXI Timer
 *
 * Hardware path:
 *   axi_timer_0/interrupt
 *      -> axi_intc_0/intr[0]
 *      -> axi_intc_0/irq
 *      -> microblaze_riscv_0/Interrupt
 *
 * Timer:
 *   100 MHz
 *   0.5 s interval
 *   Down Count + Auto Reload + Interrupt
 *
 * User callback:
 *   - interrupt_count++
 *   - timer_event = 1
 *
 * Main loop:
 *   - timer_event 확인
 *   - AXI GPIO LED0 toggle
 */

#define TIMER0                  0U
#define LED_CHANNEL             1U
#define LED0_MASK               0x00000001U

#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

#ifndef SDT
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#else
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;

#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U;
volatile u32 timer_event     = 0U;
volatile u32 led_state       = 0U;

/*
 * XTmrCtr_InterruptHandler()가 Timer HW interrupt를 처리한 뒤
 * 이 callback을 Interrupt Context에서 호출한다.
 *
 * ISR/Callback에서는 긴 처리나 출력 작업을 하지 않는다.
 */
static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;

    interrupt_count++;
    timer_event = 1U;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);

    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );

    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();

    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );

    Xil_ExceptionEnable();

#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}

int main(void)
{
    int status;

    status = InitGpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = InitTimer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = SetupInterruptSystem();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);

    /*
     * Interrupt path를 모두 준비한 뒤 Timer 시작
     */
    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        /*
         * Callback은 event만 남긴다.
         * 실제 AXI GPIO Write는 Main Context에서 수행한다.
         */
        if (timer_event != 0U) {
            timer_event = 0U;

            led_state ^= LED0_MASK;
            XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
        }
    }

    return XST_SUCCESS;
}

SUMMARY

SoC 09 완료 판정 기준

  • AXI Interrupt Controller를 추가했다.
  • Timer interrupt를 intr[0]에 연결했다.
  • irq를 MicroBlaze V Interrupt에 연결했다.
  • Timer Interrupt 입력을 Level-High로 설정했다.
  • ISR/IPR/IER/IAR/IVR/MER 역할을 구분한다.
  • Classic XIntc 초기화 흐름을 이해한다.
  • SDT에서 XSetupInterruptSystem()을 이해한다.
  • XTC_INT_MODE_OPTION을 사용한다.
  • Callback은 event만 기록한다.
  • LED Write는 Main Context에서 수행한다.
  • 약 0.5초마다 Interrupt와 LED Toggle을 확인한다.
