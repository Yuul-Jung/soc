SECTION 01실습 목표

AXI Interrupt Controller 실습 목표

08장의 Timer Polling을 Interrupt 방식으로 바꾸어 Basys3의 LED0를 약 0.5초마다 반전합니다. AXI INTC(악시 인터럽트 컨트롤러, 인터럽트 요청 제어 장치)는 Timer의 요청을 받아 MicroBlaze V CPU에 전달합니다.

AXI Timer interrupt → AXI INTC → MicroBlaze V → TimerCallback() → Main Loop → AXI GPIO → LED0
Timer 인터럽트 처리 횟수예상 LED0 출력
첫 번째 인터럽트LED0 ON
두 번째 인터럽트LED0 OFF
세 번째 인터럽트LED0 ON

09장은 08장에 axi_intc_0를 추가하고, Timer의 만료를 CPU에 하드웨어 인터럽트로 알립니다. 실제 Vitis WATCH에서 interrupt_count 12 → 35, led_state 0 → 1을 확인했고 Basys3 LED0 점멸에 성공했습니다. 정확한 주기는 정밀 계측하지 않았습니다.

SECTION 02핵심 이론

Polling과 Interrupt의 차이

08장의 Timer Polling과 09장의 Interrupt 방식이 CPU에 이벤트를 알리는 차이를 확인합니다.

항목설명
SoC 08 · Polling(폴링)Main Loop에서 XTmrCtr_IsExpired()로 Timer 상태를 계속 읽음
SoC 09 · Interrupt(인터럽트)Timer 만료 → AXI INTC → CPU 예외 진입 → Handler에서 이벤트 기록
LED를 제어하는 위치08장과 마찬가지로 최종 LED0 기록은 Main Loop가 담당

09장 Main이 확인하는 timer_event는 RAM에 있는 소프트웨어 플래그입니다. AXI Timer의 하드웨어 만료 레지스터를 반복 읽는 Polling과 구분합니다.

SECTION 03핵심 이론

AMD 원본 · AXI INTC 내부 블록도

핵심 부품은 Interrupt Detection(요청 감지), Registers(상태·허용), Interrupt Generation(출력 생성)입니다.

원본 그림의 Intr 입력으로 주변장치 인터럽트가 들어오고, Register Block에서 발생·허용·승인 상태를 관리합니다. AXI Interface는 CPU의 제어 레지스터 접근 통로입니다. 원본의 Irq는 일반 신호명이고, 이번 실제 Vivado IP의 출력 포트는 interrupt입니다.

SECTION 09핵심 이론

Interrupt ID · 실제 xparameters.h

09장 하드웨어에 맞춰 생성된 BSP 값을 기준으로 인터럽트를 연결합니다.

// 실제 09장 Vitis BSP 정의
#define XPAR_FABRIC_XTMRCTR_0_INTR        0
#define XPAR_XTMRCTR_0_INTERRUPTS         0x2000
#define XPAR_XTMRCTR_0_INTERRUPT_PARENT  0x41200001
#define XPAR_XINTC_0_BASEADDR            0x41200000

0은 이번 INTC에 연결된 첫 번째 입력에 해당합니다. 0x2000을 '인터럽트 번호 8192'라고 해석하면 안 됩니다. 0x41200001은 드라이버에서 사용할 Interrupt Parent 인코딩값이며 단순 Base Address와 다릅니다.

SECTION 12핵심 이론

ISR는 짧게 · LED0는 Main에서 제어

사용자 TimerCallback은 사건을 기록하는 데 집중하고, GPIO 출력은 Main Loop에서 수행합니다.

static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++; // IRQ 발생 횟수 증가
    timer_event = 1U;   // Main에 이벤트 통지
}

실제 WATCH 결과는 interrupt_count 12 → 35, led_state 0 → 1입니다. LED0 점멸을 실기 확인했습니다. 약 0.5초 반전 주기는 100 MHz·Timer Reset 설정에서 유도한 값으로, 정밀 계측값은 아닙니다.

SECTION 31Vivado / Vitis 실습

Timer Interrupt 동작 검증

실제 Basys3 보드에서 LED0가 정상적으로 깜빡였고, Vitis WATCH에서 인터럽트 증가 및 LED 상태 변화가 확인됐습니다.

  1. Watch
    interrupt_count, timer_event, led_state를 관찰합니다.
  2. LED0
    Timer 설정상 약 0.5초마다 LED0 토글이 예상됩니다. ISR Handler의 진입·복귀도 확인합니다.
실기 검증 완료CPU 인터럽트가 발생하고 Main Loop가 LED0를 반전함을 확인했습니다. interrupt_count가 12회 → 35회로 증가했고, led_state가 0 → 1로 바뀌었습니다.
Watch 변수첫 번째 정지 화면두 번째 정지 화면관찰 결과
interrupt_count0x0000000C (12)0x00000023 (35)23회 증가
timer_event0x000000000x00000000ISR에서 1로 설정된 뒤 Main에서 0으로 지울 수 있음
led_state0x000000000x00000001LED0 OFF → ON
실제 프로그램 제어 흐름

AXI Timer → AXI INTC → MicroBlaze V → Timer 드라이버 Handler → TimerCallback() → Main Loop → AXI GPIO → LED0

Timer 입력 100 MHz, Reset Value 49,999,998 설정상 약 0.5초마다 LED0가 반전합니다. 실제 점멸은 보드에서 확인했으며, 정확한 주기 계측은 수행하지 않았습니다.

SECTION 32Vitis 코드

Timer Interrupt main.c — 전체 코드

09장 Application에서 사용할 코드이며 상세 설명은 09.1장에 정리했습니다.

09장 Application의 Build 성공과 실제 Debug 동작을 확인했습니다. 아래 코드는 검증한 인터럽트 처리 구조를 반영한 코드입니다. 실제 사용된 SDT 구성에서는 #ifdef SDT 쪽이 선택됩니다.

main.c
#include "xparameters.h"     // 하드웨어 주소 및 장치 번호
#include "xtmrctr.h"         // AXI Timer 드라이버
#include "xgpio.h"           // AXI GPIO 드라이버
#include "xstatus.h"         // 성공/실패 반환값
#include "xil_exception.h"   // CPU 인터럽트 처리

#ifdef SDT
#include "xinterrupt_wrap.h" // SDT 기반 인터럽트 연결
#else
#include "xintc.h"          // Classic 기반 AXI INTC 드라이버
#endif

#define TIMER0             0U
#define LED_CHANNEL        1U
#define TIMER_RESET_VALUE  49999998U // 08장에서 사용한 값

#ifndef SDT
// 다음 이름은 실제 xparameters.h 확인 후 확정
#define TIMER_DEVICE_ID    XPAR_TMRCTR_0_DEVICE_ID
#define GPIO_DEVICE_ID     XPAR_GPIO_0_DEVICE_ID
#define INTC_DEVICE_ID     XPAR_INTC_0_DEVICE_ID
#define TIMER_INTR_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#else
// 다음 주소 매크로 역시 실제 BSP를 확인
#define TIMER_BASEADDR     XPAR_XTMRCTR_0_BASEADDR
#define GPIO_BASEADDR      XPAR_XGPIO_0_BASEADDR
#endif

static XTmrCtr Timer;
static XGpio Gpio;
#ifndef SDT
static XIntc Intc;
#endif

volatile u32 interrupt_count = 0U; // 발생한 인터럽트 횟수
volatile u32 timer_event = 0U;     // Main에 전달할 이벤트
volatile u32 led_state = 0U;       // LED0 상태

// Timer 드라이버에서 호출하는 사용자 Callback
static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
    timer_event = 1U;
}

static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

static int InitTimer(void)
{
    int status;
#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif
    if (status != XST_SUCCESS) return XST_FAILURE;

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) return XST_FAILURE;

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(&Timer, TIMER0,
        XTC_DOWN_COUNT_OPTION | XTC_AUTO_RELOAD_OPTION | XTC_INT_MODE_OPTION);
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);
    return XST_SUCCESS;
}

static int SetupInterruptSystem(void)
{
    int status;
#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) return XST_FAILURE;
    status = XIntc_Connect(&Intc, TIMER_INTR_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler, &Timer);
    if (status != XST_SUCCESS) return XST_FAILURE;
    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) return XST_FAILURE;
    XIntc_Enable(&Intc, TIMER_INTR_ID);
    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler, &Intc);
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(&Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId, Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY);
    if (status != XST_SUCCESS) return XST_FAILURE;
#endif
    return XST_SUCCESS;
}

int main(void)
{
    if (InitGpio() != XST_SUCCESS) return XST_FAILURE;
    if (InitTimer() != XST_SUCCESS) return XST_FAILURE;
    if (SetupInterruptSystem() != XST_SUCCESS) return XST_FAILURE;

    XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
    XTmrCtr_Start(&Timer, TIMER0);

    while (1) {
        if (timer_event != 0U) {
            timer_event = 0U;
            led_state ^= 1U;
            XGpio_DiscreteWrite(&Gpio, LED_CHANNEL, led_state);
        }
    }
}
